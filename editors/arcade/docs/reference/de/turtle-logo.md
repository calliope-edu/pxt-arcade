### MakeCode-Arcade-Erweiterung
Diese MakeCode-Arcade-Erweiterung bringt die Programmiersprache „Turtle Logo“ in MakeCode.
Der Code baut auf einer früheren Version auf ([https://github.com/microsoft/pxt-screen-turtle](https://github.com/microsoft/pxt-screen-turtle)), aber ich brauchte einige Änderungen, um die mich die Grundschullehrerin gebeten hatte, mit der ich gearbeitet habe:
- möglichst wenige Blöcke
- einige Blocknamen ändern, damit es für Schülerinnen und Schüler einfacher ist
- kartesische Koordinaten verwenden, mit (0,0) in der Mitte des Bildschirms
