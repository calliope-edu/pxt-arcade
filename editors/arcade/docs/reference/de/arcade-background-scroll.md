# Erweiterung Hintergrund-Scrollen

Das ist eine Erweiterung für [MakeCode Arcade](arcade.makecode.com) mit Blöcken zum Scrollen und Wiederholen von Hintergrundbildern.

Du kannst damit auch einen Parallax-Effekt erzeugen, indem du mehrere Ebenen unterschiedlich schnell scrollst.

Quelle: [microsoft/arcade-background-scroll](https://github.com/microsoft/arcade-background-scroll/tree/v0.1.2) (v0.1.2)

```package
arcade-background-scroll
```
