# Sprite Grid

## Usage

Sprites can be placed or "snapped" to the tilemap grid. Using blocks in this extension, sprites placed on the grid can be moved in discrete steps.

![](/static/libs/sprite-grid/image1.png)

Source: [microsoft/arcade-grid](https://github.com/microsoft/arcade-grid/tree/v1.3.0) (v1.3.0)

```package
sprite-grid
```
