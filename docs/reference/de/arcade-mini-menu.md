# arcade-mini-menu

Füge deinem MakeCode-Arcade-Spiel Menüs hinzu

Das ist eine Erweiterung für [Microsoft MakeCode Arcade](https://arcade.makecode.com/), mit der du Menüs für dein Arcade-Spiel erstellen kannst!

Einige Funktionen:

1. Menüs, die du wie Sprites verwenden kannst (mit allen Blöcken aus der Kategorie Sprites)
2. Text und Symbole
3. Automatisches Scrollen, wenn wenig Platz ist
4. Flexible Menü-Layouts: eine Spalte, eine Zeile oder ein x-y-Raster
5. Viele Stil-Optionen, damit das Menü zum Aussehen deines Spiels passt
