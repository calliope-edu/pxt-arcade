# Bild-Abbildung

Eine Erweiterung für MakeCode Arcade, mit der du Bilder auf Formen abbilden und einfach verwandeln kannst.
Damit bildest du Texturen auf Vierecke oder Farbbereiche ab und zeichnest Umrisse.

## Block-Gruppen
- Viereck-Abbildung
- Bereichs-Abbildung
- Umrisse
- Abfragen

## Viereck-Abbildung

Mit dieser Gruppe projizierst du ein Quellbild auf eine Form mit 4 Ecken.

<a id="map-to-quad"></a>
### auf Viereck abbilden

Zeichnet das Quellbild mit Hilfe der Viereck-Punkte direkt in das Zielbild.

<a id="mapped-copy-to-quad"></a>
### abgebildete Kopie auf Viereck

Bildet genauso ab, gibt aber ein neues Bild zurück, statt das Zielbild zu verändern.

## Bereichs-Abbildung

Mit dieser Gruppe bildest du ein Quellbild auf die Form eines gewählten Farbbereichs ab.

<a id="map-to-color-region"></a>
### auf Farbbereich abbilden

Bildet das Quellbild auf die Pixel des Zielbilds ab, die die gewählte Farbe haben.

<a id="mapped-copy-to-color-region"></a>
### abgebildete Kopie in Farbbereich

Gibt ein neues Bild zurück, auf das die Farbbereichs-Abbildung angewendet wurde.

<a id="region-size"></a>
### Bereichsgröße

Gibt die Breite oder Höhe des gewählten Farbbereichs zurück.

<a id="color-region-image"></a>
### Bild des Farbbereichs

Gibt ein neues Bild zurück, das nur die gewählte Bereichsfarbe enthält.

<a id="tile-map-to-color-region"></a>
### zugeschnitten auf Farbbereich abbilden

Bildet eine wiederholte bzw. zugeschnittene Version der Quelle auf den gewählten Bereich ab, mit Einstellungen für Maßstab und Versatz.

<a id="cropped-copy-to-color-region"></a>
### zugeschnittene Kopie in Farbbereich

Version des zugeschnittenen Abbildens, die eine Kopie zurückgibt. Das Zielbild bleibt unverändert.

## Umrisse

Mit dieser Gruppe zeichnest du Umrisse um alle sichtbaren Pixel oder um eine gewählte Bereichsfarbe.

<a id="draw-total-outline"></a>
### Gesamtumriss zeichnen

Zeichnet einen äußeren Umriss um alle Pixel, die nicht Hintergrund sind.

<a id="outlined-transparency-copy"></a>
### umrandete Kopie (Gesamtumriss)

Version des Gesamtumrisses, die eine Kopie zurückgibt.

<a id="draw-region-outline"></a>
### Bereichsumriss zeichnen

Zeichnet einen Umriss um die Pixel mit der Farbe `regionColor`.

<a id="outlined-region-copy"></a>
### umrandete Kopie (Bereich)

Version des Bereichsumrisses, die eine Kopie zurückgibt.

## Abfragen

Mit dieser Gruppe erstellst und änderst du Arrays mit Viereck-Punkten.

<a id="set-quad-corner"></a>
### Viereck-Ecke setzen

Ändert eine Ecke (`TL`, `TR`, `BL` oder `BR`; im Block OL, OR, UL, UR für oben links, oben rechts, unten links, unten rechts) in vorhandenen x/y-Punkt-Arrays.

<a id="make-quad-x-points"></a>
### Viereck-x-Punkte erstellen

Erstellt das Array der x-Koordinaten für die Viereck-Abbildung.

<a id="make-quad-y-points"></a>
### Viereck-y-Punkte erstellen

Erstellt das Array der y-Koordinaten für die Viereck-Abbildung.
