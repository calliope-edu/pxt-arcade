# Sprite-Raster

## Verwendung

Sprites können auf das Raster der Tilemap gesetzt oder daran „eingerastet“ werden. Mit den Blöcken dieser Erweiterung kannst du Sprites auf dem Raster in festen Schritten bewegen.
