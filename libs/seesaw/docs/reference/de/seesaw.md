# seesaw (Beta)

Ein MakeCode-Paket für das Adafruit-Seesaw-I2C-Protokoll

Ein MakeCode-Paket für das [Adafruit-Seesaw-I2C-Protokoll](https://learn.adafruit.com/adafruit-seesaw-atsamd09-breakout?view=all).

## Verwendung

* Öffne **Fortgeschritten**, **Erweiterungen**, suche nach **seesaw** und füge es deinem Projekt hinzu.

Erstelle ein ``seesaw.Seesaw``-Objekt und rufe seine Funktionen auf.
Optional kannst du im Konstruktor die I2C-Geräteadresse übergeben.

Quelle: [adafruit/pxt-seesaw](https://github.com/adafruit/pxt-seesaw/tree/v0.0.19) (v0.0.19)

```package
seesaw
```
