# Fonctionnalités de l'éditeur MakeCode

La fenêtre de l'éditeur MakeCode a de nombreuses fonctionnalités pour vous aider à créer, télécharger et enregistrer vos projets de codage.

## Créer des blocs et du code

### Boîte à outils des blocs

Les blocs que vous utilisez dans votre projet se trouvent dans la **boîte à outils**. La boîte à outils est une liste de catégories de blocs sur le côté pour différentes fonctions et opérations de code. Pour obtenir un bloc de la boîte à outils, vous sélectionnez une catégorie de bloc et un ensemble de blocs s'ouvre, vous montrant les blocs disponibles. Vous saisissez un bloc de l'étagère et le tirez sur l'espace de travail. Il est également possible de lancer une recherche, pour vous aider à trouver les blocs qui vous intéressent.

#### #blocks-images

### Éditeur JavaScript

L'éditeur JavaScript est un éditeur de texte entièrement fonctionnel et sensible au code. Cela signifie qu'il peut aider à compléter les fonctions et les instructions en vous fournissant des suggestions et en faisant de l’auto complétion. Une description détaillée de l'editeur JavaScript et de ses fonctionnalités est disponible ici: https://makecode.com/js/editor.

## Contrôles de l'Éditeur

### Accueil

Le bouton **Accueil** vous amène à l' [écran d'accueil](@homeurl@) qui montre les projets récents et d'autres activités.

#### #home-images

### Partager #share

Le bouton **partager** affiche la fenêtre **Partager le projet** qui vous permet de publier votre projet dans le nuage public (cloud).

#### #share-images

### Blocs ou JavaScript #blocksjs

Pour commuter la vue de votre code des **blocs** vers **JavaScript**, ou dans l'autre sens, appuyez sur un des boutons de vue en haut au centre de la fenêtre.

#### #blocksjs-images

### Aide #help

Le bouton **aide** affiche un menu d'options d'aide qui vous dirigent vers l'assistance ou les pages de référence.

#### #help-images

### Plus #moresettings

Le bouton **Plus ** affiche un menu des paramètres du projet et des options.

#### #moresettings-images

### Annuler et rétablir #undoredo

Vous pouvez annuler et rétablir des modifications récentes que vous effectuez soit au niveau des **blocs**, soit au niveau du code **JavaScript** avec les boutons **Annuler** et **Rétablir**, en bas à droite de la fenêtre de l'éditeur.

#### #undoredo-images

### Zoom avant et zoom arrière #zoom

Il y a deux boutons de zoom dans la partie inférieure droite de la vue de l'éditeur. Le bouton **(+)** permet un zoom avant et le bouton **(-)** permet un zoom arrière. Les boutons de zoom changent la taille des blocs lorsque vous êtes dans la vue **blocs**. Lorsque vous travaillez avec le code dans la vue **JavaScript**, les boutons de zoom changent la taille du texte.

#### #zoom-images

### Enregistrer le projet #saveproject

Vous pouvez choisir un nom pour votre projet et l'enregistrer. Saisissez un nom pour le projet et appuyez sur l' **icône de disquette** pour l'enregistrer.

#### #saveproject-images

### Télécharger #download

Le bouton **Télécharger** copiera votre programme sur un lecteur de votre ordinateur. Vous pouvez copier votre programme directement sur votre @boardname@ si elle est connectée et qu'un lecteur apparaît sur votre ordinateur.

#### ~ hint

**Nom du projet et nom du fichier téléchargé**

Lorsque vous téléchargez le programme pour votre projet, le nom que vous avez donné au projet devient partie intégrante du fichier téléchargé. Si vous décidez de renommer le fichier téléchargé, le nom que vous avez choisi pour le projet, et non celui qui est en cours, est utilisé et affiché par l'éditeur.

#### ~

#### #download-images

### Explorateur #explorer

Tous les fichiers de votre projet sont affichés dans l'explorateur. Cliquez sur le bouton **Explorateur** pour agrandir la vue Explorateur et voir tous les fichiers du projet. Aussi, en plus de vos fichiers de projet, l'Explorateur montrera tous les fichiers utilisés pour coder tous les blocs dans l'éditeur. Lorsque vous cliquez et sélectionnez un fichier, il s'ouvre dans l'éditeur afin de le visualiser et de modifier si vous le souhaitez.

#### #explorer-images
