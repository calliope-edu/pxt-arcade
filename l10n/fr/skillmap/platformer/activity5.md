## Règles de l'IA @showdialog

Le code de ce programme fait apparaître des ennemis sur les tuiles violettes **[ ! ]**.
Dès que les ennemis apparaissent, ils commencent à se déplacer vers la gauche et restent
coincés contre un mur... alors ajoutons de la logique pour que les ennemis ne soient plus bloqués.

---

**Les ennemis devront suivre deux règles :**

1. **Si l'ennemi est sur le point de foncer dans un mur, il essaie de sauter par-dessus**
2. **Si l'ennemi touche quand même un mur, il fait demi-tour**


---


Chacune de ces règles a une *condition* et une *action*.

Si la condition est remplie, l'action se produit.
Nous devons écrire du code qui vérifie en permanence chacune de ces conditions.

## Boucles, partie 1

Pour commencer, nous avons besoin d'un conteneur **quand mise à jour du jeu** qui déclenche du code
à chaque fois que quelque chose change dans le jeu. À l'intérieur, nous avons besoin d'une boucle pour vérifier
chacun des ennemis, un par un.

---


► Fais glisser un bloc ``||game:quand mise à jour du jeu||`` et place-le dans l'espace de travail.

► Emboîte un bloc ``||loops: pour l’élément [value] de [list]||`` dans le
conteneur **quand mise à jour du jeu**.

```blocks
let list: number[] = [];
game.onUpdate(function () {
    for (let value of list) {
    }
})
```

## Sauter, partie 1

Commençons le code de notre première règle :

> 1. **Si l'ennemi est sur le point de foncer dans un mur, il essaie de sauter par-dessus**

---


► Nous allons devoir vérifier **si** quelque chose est vrai. Pour cela, fais glisser
un conteneur logique ``||logic: si <vrai> alors||`` dans le conteneur vide **quand mise à jour du jeu**.

► Vérifie maintenant que l'ennemi n'est pas déjà en train de sauter en remplaçant
``||logic: <vrai>||`` par ``||scene: [monSprite] touche-t'il le mur [gauche]||`` dans l'en-tête vide
du bloc **si/alors**.

► Remplace ``||variables(noclick): monSprite||`` par ``||variables(noclick): value||`` pour être sûr
que c'est l'ennemi actuel qui est vérifié.

## Sauter, partie 2

Maintenant que nous savons que l'ennemi est au sol, il y a deux situations
où il doit sauter :
 - S'il se déplace vers la gauche et qu'il y a un mur à gauche
 - S'il se déplace vers la droite et qu'il y a un mur à droite

Nous allons déterminer si l'une de ces situations se produit à l'aide d'une nouvelle instruction **si/alors**.

---


► Fais glisser un autre bloc ``||logic:si <vrai> alors||`` et place-le à l'intérieur
de celui, vide, qui est déjà dans la boucle **pour l’élément**.

► Pour vérifier si deux choses sont vraies en même temps (déplacement vers la gauche **et** mur à gauche),
fais glisser un bloc ``||logic: < > et < >||`` pour remplacer l'argument ``||logic:<vrai>||``
dans la nouvelle instruction **si/sinon**.

► Dans la case de droite (à droite du **et**), emboîte un bloc ``||scene: la tuile [gauche] par rapport à [monSprite] est [ ]||``

► Remplace ``||variables(noclick): monSprite||`` par ``||variables(noclick): value||`` et remplace la tuile
vide par la tuile **[X]**.

► Place un bloc ``||logic: [0] [<] [0]||`` à gauche du **et**.

---

Nous en ferons plus à l'étape suivante.

## Sauter, partie 3

Nous vérifions déjà si la tuile suivante à gauche est un mur,
mais cela n'a d'importance que si l'ennemi se déplace vers la gauche.

Ajoutons le code qui vérifie si l'ennemi se déplace vers la gauche.

---

Dans le système d'Arcade, la gauche est négative et la droite est positive. Pour vérifier que le
sprite se déplace vers la gauche, tu dois t'assurer que sa vitesse dans la direction x
est négative.

► Prends un bloc d'argument ``||sprites: [monSprite] [x]||`` pour remplacer le
premier **0** dans ``||logic: [0] [<] [0]||``.

► Remplace ``||variables(noclick): monSprite||`` par ``||variables(noclick): value||`` et remplace
**x** par **vx (vitesse selon x)**.



```blocks
game.onUpdate(function () {
    for (let value of sprites.allOfKind(SpriteKind.Enemy)) {
        if (value.isHittingTile(CollisionDirection.Bottom)) {
            if (value.vx < 0 && value.tileKindAt(TileDirection.Left, myTiles.tile1)) {
            }
        }
    }
})
```


## Sauter, partie 6

Si l'ordinateur arrive à ce point du code, cela signifie que c'est le moment pour
l'ennemi de sauter.

---


► Dans l'instruction **si/alors** que tu viens de construire, emboîte un bloc ``||sprites:définir [monSprite] [x] à [0]||``.

► Remplace ``||variables(noclick): monSprite||`` par ``||variables(noclick): value||`` et remplace
``||sprites: x||`` par ``||sprites: vy (vitesse selon y)||``.

► Change **0** en **-150**.

```blocks
game.onUpdate(function () {

```


## Sauter, partie 7

Ensuite, nous allons ajouter le code qui fait la même chose vers la droite.

---


► Clique deux fois sur le bouton **⊕** en bas de l'instruction **si/alors** la plus intérieure
que nous venons de terminer, pour ajouter une clause **sinon** puis une clause **sinon si**.

► Duplique toute l'instruction **et**, puis dépose la copie dans l'
en-tête de la clause **sinon si**.

► Dans la nouvelle clause, change **<** en **>** et **gauche** en **droite**.

► Duplique le bloc ``||sprites:définir [value] [vy (vitesse selon y)] à [-150]||``
et emboîte la copie dans l'instruction vide **sinon si**.

► Nous en avons fini avec cette instruction **si/sinon si**, tu peux donc cliquer sur le
**⊖** à côté de la clause vide **sinon** pour la retirer du bloc.



```blocks
game.onUpdate(function () {
    for (let value of sprites.allOfKind(SpriteKind.Enemy)) {
        if (value.isHittingTile(CollisionDirection.Bottom)) {

                value.vy = -150
            } else if (value.vx > 0 && value.tileKindAt(TileDirection.Right, myTiles.tile1)) {
                value.vy = -150
            }
```
```blocks
        }
    }
})
```

## Rebondir sur les murs, partie 2

Enfin, nous devons ajouter le code qui fait tourner les ennemis vers la droite s'ils
allaient vers la gauche, et vers la gauche s'ils allaient vers la droite.

---


► Fais deux copies d'un des blocs ``||sprites:définir [value] [vy (vitesse selon y)] à [-150]||`` de la clause **si/alors**
d'origine et emboîte-en une dans chacune des clauses vides **sinon si**.

► Pour le bloc **définir value** dans la première clause **sinon si**
(**sinon si <value touche-t'il le mur gauche> alors**), change
**vy (vitesse selon y)** en **vx (vitesse selon x)** et **-150** en **30**.

► Pour le bloc **définir value** dans la deuxième clause **sinon si**
(**sinon si <value touche-t'il le mur droite> alors**), change
**vy (vitesse selon y)** en **vx (vitesse selon x)** et **-150** en **-30**.


```blocks
game.onUpdate(function () {
    for (let value of sprites.allOfKind(SpriteKind.Enemy)) {
        if (value.isHittingTile(CollisionDirection.Bottom)) {
            if (value.vx < 0 && value.tileKindAt(TileDirection.Left, myTiles.tile1)) {
                value.vy = -150
            } else if (value.vx > 0 && value.tileKindAt(TileDirection.Right, myTiles.tile1)) {
                value.vy = -150
            }
        } else if (value.isHittingTile(CollisionDirection.Left)) {
            value.vx = 30
        } else if (value.isHittingTile(CollisionDirection.Right)) {
            value.vx = -30
        }
    }
})
```
