## Dégâts, partie 1 @showdialog

Maintenant, les ennemis devraient se déplacer vers le personnage.

Que se passe-t-il quand les ennemis atteignent le personnage ? **Rien ?!?**
Bon, ce n'est pas très amusant.
Ajoutons du code pour rendre ça plus palpitant.
😈👿😈 &nbsp;  😱

---


**Notre personnage et les ennemis peuvent se rencontrer dans deux**
[**_conditions_**](#condy "quelque chose que nous devons savoir avant de décider de ce qui se passe ensuite") **différentes** :

1. **Si le personnage saute sur un ennemi, l'ennemi est détruit**

2. **Si le personnage fonce dans un ennemi,
le personnage perd de la vie et l'ennemi est détruit**


---

Nous avons besoin d'un événement de **chevauchement de sprites** pour savoir si cela arrive !

## Dégâts, partie 2
Dans les deux cas de chevauchement, nous voulons détruire le sprite de l'ennemi... alors
programmons cette partie en premier.
💥👿💥

---


► Dans la catégorie ``||sprites: Sprites||``, fais glisser un conteneur
[__*événement*__](#eventTime "élément qui fait se passer quelque chose quand une action précise a lieu")
``||sprites: quand [sprite] de type [Player] chevauche [autreSprite] de type [Player]||``
 dans l'espace de travail.

► Laisse le premier type sur **Player** et change le second type en **Enemy**.

► Place un bloc ``||sprites: détruire [monSprite]  ⊕||`` dans le nouveau conteneur d'événement.

► Fais glisser l'argument ``||variables(noclick): autreSprite||`` de l'événement **quand sprite chevauche**
pour remplacer la variable ``||variables(noclick): monSprite||`` dans le bloc détruire.

```blocks
sprites.onOverlap(SpriteKind.Player, SpriteKind.Enemy, function (sprite, autreSprite) {
    autreSprite.destroy()
```
