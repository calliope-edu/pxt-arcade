# Visual Studio Code

[Visual Studio Code](https://code.visualstudio.com) est un éditeur de code source libre ouvert que vous pouvez utiliser pour éditer vos programmes.

Working from Visual Studio Code allows you to benefit from all the features of a professional IDE while working with PXT: working with files, git integration (or source control of your choice), hundreds of extensions.

* compilation en tâche de fond
* auto-complétion
* intégration de la ligne de commande pxt

**Suivez [ces instructions](https://makecode.com/cli) ** pour configurer votre machine et éditer vos programmes dans le Visual Studio Code.
