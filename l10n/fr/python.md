# Python

L'environnement de programmation Microsoft MakeCode utilise Python en plus du langage [JavaScript](/javascript).

Ces sujets offrent une brève introduction à Python avec MakeCode :

* **[Appeler](/python/call)** - Comment utiliser une fonction
* **[Séquencement](/python/sequence)** - Ordonner les instructions dans le code
* **[Variables](/python/variables)** - Mémoriser des données et enregistrer des valeurs
* **[Opérateurs](/python/operators)** - Opérations pour modifier et comparer des valeurs
* **[Instructions](/python/statements)** - Les éléments du code qui agissent
* **[Fonctions](/python/functions)** - Des portions de code à réutiliser encore et encore
* **[Classes](/python/classes)** - Regrouper des données et des opérations liées
