# Opérateur d'assignation (=)

Utilisez un signe égal pour faire en sorte qu'une [variable](/blocks/variables/var) stocke le [nombre](/types/number), la [chaîne](/types/string) ou la valeur [booléenne](/types/boolean) souhaitée.

```block
let myNumber = 7
let myString = "Yellow Whirled"
let myLogic = true
```

Lorsque vous utilisez le signe égal pour stocker quelque chose dans une variable, le signe égal est appelé un *opérateur d'assignation*, et ce que vous stockez est appelé une *valeur*. Une valeur peut être un *littéral* , comme `20` ou `"Rêver"`. Ou, une valeur peut être une autre variable que vous voulez copier, ```let newItem = oldItem```.

Voici un exemple d'assignation de variable :

```typescript
let perfect = 10;
let extra = 1;
let extraPerfect = perfect + extra;
```

## ~hint

Vous pouvez utiliser l'opérateur d'assignation avec des variables de chaque [type](/types). Un *type* est le type de chose qu'une variable peut stocker, comme un nombre ou une chaîne.
