# Variables

[Assigner](/blocks/variables/assign) (définir) la valeur d'une variable

```block
let x = 1;
```

Obtient la valeur d'une variable

```block
let x = 1;
let y = x;
```

[Modifier](/blocks/variables/change) la valeur d'une variable

```block
let x = 0;
x+=1;
```
