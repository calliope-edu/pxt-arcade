# Navigateur recommandé pour Mac

Lorsque vous utilisez un Mac, il est recommandé d'utiliser [Safari](http://www.apple.com/safari/). Alternativement, [Google Chrome](https://www.google.com/chrome/) et [Mozilla Firefox](https://www.mozilla.org/en-US/firefox/new/) sont également pris en charge.

Regardez [ici](/browsers/technical) pour trouver les informations techniques sur les navigateurs qui sont pris en charge, ou [ici](/browsers) pour vérifier la version que vous utilisez.
