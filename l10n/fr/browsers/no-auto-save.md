# Pas d'enregistrement automatique

Dans certains cas, MakeCode ne peut pas enregistrer tout seul votre projet. Lorsque cela se produit, vous devrez faire attention à sauvegarder vos projets avant de quitter la fenêtre pour vous assurer de ne pas perdre votre progression. Il existe plusieurs façons de faire cela en fonction de l’éditeur que vous utilisez :

* Créez un lien de partage pour le projet, cela le stockera dans le cloud.
* Enregistrez votre projet à l’aide de l’option « Enregistrer le projet » dans le menu des paramètres du projet.
* Enregistrez votre projet en PNG
* Pour les éditeurs qui incluent du matériel, un fichier hexadécimal téléchargé peut être rechargé dans l'éditeur

## Les causes courantes de la désactivation de la sauvegarde automatique

* Navigation privée : Si vous ouvrez MakeCode dans le mode 'navigation privée' de vos navigateurs, il ne parviendra probablement pas à enregistrer les projets - selon le navigateur, ils seront peut-être sauvegardés seulement jusqu'à ce que la fenêtre du navigateur ne soit fermée, ou jusqu'à ce que la fenêtre ne soit actualisée.
* Stockage plein: Le navigateur alloue une certaine quantité d'espace pour chaque site Web, il est donc possible que vous n'ayez plus de place. Si c'est le cas, vous devrez peut-être essayer de libérer de l'espace sur votre disque dur, ou supprimer les anciens projets.
* Stockage désactivé : De nombreux navigateurs ont des options pour désactiver entièrement le stockage local ou les cookies. Si ces paramètres sont activés dans votre navigateur, vous devrez peut-être les désactiver pour que l'enregistrement automatique fonctionne à nouveau.
