# Navigateur recommandé pour Linux

Si vous utilisez Linux, il est recommandé d'utiliser [Mozilla Firefox](https://www.mozilla.org/en-US/firefox/new/) ou [Google Chrome](https://www.google.com/chrome/).

Regardez [ici](/browsers/technical) pour trouver les informations techniques sur les navigateurs qui sont pris en charge, ou [ici](/browsers) pour vérifier la version que vous utilisez.
