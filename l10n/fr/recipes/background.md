# Tutoriel arrière-plan

## {Introduction @unplugged}

L'image d'arrière-plan est ennuyeuse ? Suivez ce tutoriel pour apprendre à changer la couleur de fond ou dessiner une image par dessus.

## {Step 1: set the background color}

A partir de `||scene:Scène||`, prenez le bloc `||scene:définir couleur d'arrière-plan||` pour changer la couleur de l'arrière-plan de votre jeu.

```blocks
scene.setBackgroundColor(6)
```

## {Step 2: set the background image}

A partir de `||scene:Scène||`, prenez le bloc `||scene:définir couleur d'arrière-plan||` pour changer l'image de fond.

Lorsque le jeu s'exécute, les couleurs d'arrière-plan sont appliquée; suivi de l'image d'arrière-plan.

## {Step 3: Change color or background during the game}

Vous pouvez également changer la couleur, ou l'image pendant le jeu. Les blocs ci-dessous rendront l'arrière-plan rouge lorsque le bouton **A** est pressé. Essayez donc !

```blocks
controller.A.onEvent(ControllerButtonEvent.Pressed, function () {
    scene.setBackgroundColor(2)
})
controller.A.onEvent(ControllerButtonEvent.Released, function () {
    scene.setBackgroundColor(6)
})
```
