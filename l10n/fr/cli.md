# Interface de ligne de commande

Il est possible d'utiliser les outils à partir de l' **interface de ligne de commande de pxt (CLI)**. `Pxt` peut:

* Éditer, compiler ou déployer des programmes en JavaScript.
* Intégrez facilement dans la plupart des IDEs. Il est fourni avec la prise en charge intégrée de [Visual Studio Code](/code).
* Exécutez un serveur Web local pour l'éditeur Web.
* Author extensions using JavaScript and/or C++.

Using the PXT CLI assumes that you have some experience with programming and will require installation of additional tools on your machine.

* **[COMMENÇONS](https://makecode.com/cli)**
