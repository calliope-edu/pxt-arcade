# Fonction

Une fonction vous permet de créer une partie de code que vous pouvez réutiliser dans votre programme. Vous créez une fonction à l'aide d'une *définition* de fonction qui nomme la fonction et a son code. Un *appel* de fonction est lorsque vous utilisez une fonction par son nom quelque part dans votre programme.

## Définir une fonction

Une [**définition**](/types/function/define) de fonction est un bloc qui a le nom de la fonction et son code.

```block
function doSomething() {
}
```

## Appeler une fonction

Un [**appel**](/types/function/call) de fonction est lorsque vous souhaitez utiliser le code dans la fonction à un endroit quelconque dans votre programme.

```sig
function doSomething() {
}
doSomething();
```
