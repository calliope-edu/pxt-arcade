# Enregistrer des projets

Les programmes que tu crées dans MakeCode sont enregistrés comme projets dans la mémoire locale de ton navigateur. Ton programme est enregistré comme projet, que tu lui donnes un nom ou non. Si tu ne l'enregistres pas sous un nom, il reste dans la mémoire locale comme projet « Sans titre ».

En bas de la fenêtre de l'éditeur se trouve une zone d'enregistrement : tu peux y taper un nom et appuyer sur le bouton disquette pour enregistrer le projet actuel sous ce nom.

## Que contient un projet ?

Un projet se compose principalement de quatre fichiers :

* _main.ts_
* _main.blocks_
* _README.md_
* _pxt.json_

Ces fichiers contiennent le code source JavaScript, les attributs et les positions des blocs, ainsi que les informations sur les dépendances.

## Emplacement et durée de conservation

Les fichiers du projet sont stockés comme données dans la base de données indexée du navigateur. Les données du projet sont associées à un identifiant du projet et à l'adresse du site [Arcade](https://arcade.calliope.cc). La base de données ne conserve pas les projets pour toujours : ils sont supprimés quand tu effaces le cache et les fichiers temporaires du navigateur. Les règles selon lesquelles les navigateurs vident leur cache et leurs données sont définies par la politique [W3C Clear Site Data](https://www.w3.org/TR/clear-site-data/).
