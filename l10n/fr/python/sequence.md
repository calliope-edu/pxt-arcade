# Séquences

En appelant une fonction après l'autre, dans l'ordre, tu peux faire exécuter au programme des séquences de choses différentes.

```python-ignore
doSomething()
doAnotherThing()
```

## L'instruction pass

En Python, il existe le concept d'*instruction vide* : le mot-clé `pass` là où une instruction est attendue. L'instruction `pass` sert d'_espace réservé_ pratique pour une ou plusieurs instructions que le programmeur complétera plus tard pour terminer une fonctionnalité.

```python-ignore
def myUnfinished():
    # Fill in code later to complete this function!
    pass
```
