# JavaScript

L'environnement de programmation Microsoft MakeCode utilise JavaScript avec le langage [Static TypeScript](https://makecode.com/language) .

Ces sujets donnent une brève introduction à JavaScript avec MakeCode:

* **[Appels](/javascript/call)** - Comment utiliser une fonction
* **[Séquences](/javascript/sequence)** - Ordonner les instructions dans le code
* **[Variables](/javascript/variables)** - Mémoriser des données et enregistrer des valeurs
* **[Opérateurs](/javascript/operators)** - Opérations pour modifier et comparer des valeurs
* **[Instructions](/javascript/statements)** - Les éléments du code qui agissent
* **[Fonctions](/javascript/functions)** - Des morceaux de code à réutiliser encore et encore
* **[Types](/javascript/types)** - L'identité des données
* **[Classes](/javascript/classes)** - Regrouper des données et des opérations liées
* **[Interfaces](/javascript/interfaces)** - Une manière régulière de travailler avec une classe
* **[Génériques](/javascript/generics)** - Utiliser différentes données avec le même code
