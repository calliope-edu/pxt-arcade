# Fléchettes

Une extension pour créer des fléchettes à lancer, avec des propriétés de trajectoire que tu peux modifier.

## Créer

```cards
darts.create(img``, SpriteKind.Player)
```

## Actions

```cards
darts.create().controlWithArrowKeys()
darts.create().throwDart()
darts.create().stopDart()
darts.create().setTrace()
```
