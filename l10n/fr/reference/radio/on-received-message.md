# on Received Message

Exécute une partie d'un programme lorsque la @boardname@ reçoit un
message par ``radio``.

```sig
radio.onReceivedMessage(0, function() {})
```

## Paramètres

* **msg** : le message à attendre. Voir [envoyer un message](/reference/radio/send-message)
