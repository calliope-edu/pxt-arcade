# envoyer chaîne

Envoie une chaîne de caractères aux autres @boardname@s à proximité connectées par radio. La
longueur maximale de la chaîne est de 19 caractères.

```sig
radio.sendString("Hello!")
```

## Paramètres

* **msg** : une [chaîne](/types/string) à envoyer par radio.
