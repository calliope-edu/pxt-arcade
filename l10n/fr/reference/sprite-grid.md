# Grille de sprites

## Utilisation

Les sprites peuvent être placés ou « aimantés » sur la grille de la carte de tuiles. Avec les blocs de cette extension, les sprites placés sur la grille peuvent être déplacés pas à pas.

![](/static/libs/sprite-grid/image1.png)

Source: [microsoft/arcade-grid](https://github.com/microsoft/arcade-grid/tree/v1.3.0) (v1.3.0)

sprite-grid
