### Extension MakeCode Arcade
Cette extension MakeCode Arcade ajoute le langage de programmation « Turtle Logo » à MakeCode.
Ce code s'appuie sur une version précédente ([https://github.com/microsoft/pxt-screen-turtle](https://github.com/microsoft/pxt-screen-turtle)), mais j'avais besoin de quelques modifications spécifiques demandées par l'enseignante de primaire avec qui je travaillais :
- réduire au minimum le nombre de blocs
- changer le nom de certains blocs pour aider les élèves
- utiliser des coordonnées cartésiennes, (0,0) étant au centre de l'écran
