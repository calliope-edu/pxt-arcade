### Extension MakeCode Arcade
Cette extension MakeCode Arcade apporte le langage de programmation « Turtle Logo » dans MakeCode.
Le code s'appuie sur une version antérieure ([https://github.com/microsoft/pxt-screen-turtle](https://github.com/microsoft/pxt-screen-turtle)), mais j'avais besoin de quelques modifications demandées par l'enseignante d'école primaire avec qui j'ai travaillé :
- le moins de blocs possible
- changer certains noms de blocs pour que ce soit plus simple pour les élèves
- utiliser des coordonnées cartésiennes, avec (0,0) au centre de l'écran
