# min

Le minimum de deux valeurs.

```sig
Math.min(8, 2);
```

Trouver le plus petit de deux nombres avec la fonction **min** .

## Paramètres

**a**: le premier nombre à vérifier pour voir s'il est plus que le deuxième nombre. **b**: le deuxième nombre à vérifier pour voir s'il s'agit d'un nombre inférieur au premier nombre.

## Valeur retournée

* le plus petit des deux nombres `a` ou `b`.

## Exemple

Découvrez quelle valeur est la plus petite: `2` ou `9`.

```blocks
let minival = Math.min(2, 9);
```
