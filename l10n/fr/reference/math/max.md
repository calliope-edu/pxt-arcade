# max

Le maximum de deux valeurs.

```sig
Math.max(8, 2);
```

Vous trouvez le plus grand de deux nombres avec la fonction **Max** .

## Paramètres

**a**: le premier nombre à vérifier pour voir s'il est plus que le deuxième nombre. **b**: le deuxième nombre à vérifier pour voir s'il s'agit d'un nombre supérieur au premier nombre.

## Valeur retournée

* le plus grand des deux nombres entre `a` et `b`.

## Exemple

Découvrez quelle est la valeur la plus grande: `7` ou `16`.

```blocks
let minival = Math.max(7, 16);
```
