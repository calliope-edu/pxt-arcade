# reset

Réinitialise la carte et redémarre le programme depuis le début.

```sig
control.reset()
```

Tout ce que le programme a fait avec la carte est remis dans l'état où il était avant le
démarrage du programme. Le programme recommence depuis le début.

## Exemple #example

Réinitialise la carte et recommence.

```blocks
control.reset()
```
