## Ajouter un effet d'écran

Donne un petit plus à ton projet avec des effets d'écran.

Les effets d'écran ajoutent des particules sur l'écran de ton projet. Pour utiliser des effets d'écran, ajoute le bloc à ton projet et choisis l'effet que tu veux dans la liste déroulante.


### Exemple de code

```blocks
effects.bubbles.startScreenEffect()

```
