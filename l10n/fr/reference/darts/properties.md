# Propriétés

Propriétés qui contrôlent la trajectoire de la fléchette.

## angle

L'angle d'incidence du lancer.

### obtenir

```block
let myDart: Dart = null
let angle = myDart.angle
```

### définir

```block
let myDart: Dart = null
myDart.angle = 10
```

## pow

La force de lancer appliquée à la fléchette.

### obtenir

```block
let myDart: Dart = null
let power = myDart.pow
```

### définir

```block
let myDart: Dart = null
myDart.pow = 50
```

## gravité

La force vers le bas appliquée à la fléchette pendant son trajet.

### obtenir

```block
let myDart: Dart = null
let gravity = myDart.gravity
```

### définir

```block
let myDart: Dart = null
myDart.gravity = 20
```

## vent

La force horizontale qui pousse la fléchette.

### obtenir

```block
let myDart: Dart = null
let wind = myDart.wind
```

### définir

```block
let myDart: Dart = null
myDart.wind = 0
```

## traceColor

La couleur de la ligne de trace de la fléchette.

### obtenir

```block
let myDart: Dart = null
let traceColor = myDart.traceColor
```

### définir

```block
let myDart: Dart = null
myDart.traceColor = 1
```

## angleRate

La vitesse à laquelle l'angle du lancer change avec les touches fléchées.

### obtenir

```block
let myDart: Dart = null
let angleRate = myDart.angleRate
```

### définir

```block
let myDart: Dart = null
myDart.angleRate = 1
```

## powerRate

La vitesse à laquelle la puissance du lancer change avec les touches fléchées.

### obtenir

```block
let myDart: Dart = null
let powerRate = myDart.powerRate
```

### définir

```block
let myDart: Dart = null
myDart.powerRate = 1
```

## iter

La résolution de la ligne de trace affichée pour la trajectoire de la fléchette.

### obtenir

```block
let myDart: Dart = null
let iter = myDart.iter
```

### définir

```block
let myDart: Dart = null
myDart.iter = 3
```
