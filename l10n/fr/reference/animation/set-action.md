# définir l'action

Démarre une action d'animation attachée à un sprite.

```sig
animation.setAction(null, 0)
```

Les animations attachées à un sprite ont différentes actions. L'animation est [créée](/reference/animation/create-animation) avec un type d'action comme ``Walking`` ou ``Jumping``. Ainsi, tu peux activer différentes animations quand tu veux, simplement en définissant une nouvelle action.

## Paramètres

* **sprite** : le sprite pour lequel démarrer une action d'animation.
* **action** : l'action d'animation à démarrer sur le sprite.
