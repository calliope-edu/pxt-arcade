# Mappage d'images

Une extension pour MakeCode Arcade permettant le mappage d'images et des transformations simples basées sur des formes.
Utilise-la pour mapper des textures sur des quadrilatères, mapper des textures sur des régions de couleur et dessiner des contours.

## Groupes de blocs
- Mappage sur quadrilatère
- Mappage sur région
- Contours
- Requête

## Mappage sur quadrilatère

Utilise ce groupe pour projeter une image source sur une forme à 4 coins.

<a id="map-to-quad"></a>
### mapper sur un quadrilatère

Dessine l'image source directement sur l'image cible à l'aide des points du quadrilatère.

<a id="mapped-copy-to-quad"></a>
### copie mappée sur un quadrilatère

Même comportement de mappage, mais renvoie une nouvelle image au lieu de modifier la cible d'origine.

## Mappage sur région

Utilise ce groupe pour mapper une image source dans la forme d'une région de couleur choisie.

<a id="map-to-color-region"></a>
### mapper sur une région de couleur

Mappe l'image source sur les pixels de la cible qui correspondent à la couleur choisie.

<a id="mapped-copy-to-color-region"></a>
### copie mappée sur une région de couleur

Renvoie une nouvelle image à laquelle le mappage sur région de couleur a été appliqué.

<a id="region-size"></a>
### taille de la région

Renvoie la largeur ou la hauteur de la région de couleur choisie.

<a id="color-region-image"></a>
### image de région de couleur

Renvoie une nouvelle image qui contient uniquement la couleur de région choisie.

<a id="tile-map-to-color-region"></a>
### mapper en recadrant sur une région de couleur

Mappe une version répétée/recadrée de la source dans la région choisie, avec des réglages d'échelle et de décalage.

<a id="cropped-copy-to-color-region"></a>
### copie recadrée sur une région de couleur

Version du mappage recadré qui renvoie une copie. La cible d'entrée reste inchangée.

## Contours

Utilise ce groupe pour dessiner des contours autour de tous les pixels visibles ou autour d'une couleur de région choisie.

<a id="draw-total-outline"></a>
### dessiner le contour total

Dessine un contour extérieur autour de tous les pixels qui ne font pas partie de l'arrière-plan.

<a id="outlined-transparency-copy"></a>
### copie avec contour de transparence

Version du dessin de contour total qui renvoie une copie.

<a id="draw-region-outline"></a>
### dessiner le contour d'une région

Dessine un contour autour des pixels correspondant à `regionColor`.

<a id="outlined-region-copy"></a>
### copie avec contour de région

Version du dessin de contour de région qui renvoie une copie.

## Requête

Utilise ce groupe pour créer et modifier des tableaux de points de quadrilatère.

<a id="set-quad-corner"></a>
### définir un coin du quadrilatère

Met à jour un coin (`TL`, `TR`, `BL` ou `BR`) dans des tableaux de points x/y existants.

<a id="make-quad-x-points"></a>
### créer les points x du quadrilatère

Crée le tableau des coordonnées x pour le mappage sur quadrilatère.

<a id="make-quad-y-points"></a>
### créer les points y du quadrilatère

Crée le tableau des coordonnées y pour le mappage sur quadrilatère.
