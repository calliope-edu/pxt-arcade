# fin du jeu, le joueur gagne

Termine le jeu et désigne un joueur gagnant.

```sig
mp.gameOverPlayerWin(mp.playerSelector(mp.PlayerNumber.One))
```

## Paramètres

* **player** : le [joueur](/types/player) qui gagne le jeu.

## Exemple #example

Fais bouger deux sprites de joueurs sur l'écran. Place un sprite de nourriture (donut) sur le côté gauche de l'écran. Quand un sprite de joueur atteint le donut, ce joueur gagne le jeu.
