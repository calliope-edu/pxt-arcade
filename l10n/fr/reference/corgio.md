# Corgio

Une petite extension pour t'aider à créer un jeu de plateforme avec un corgi.

## Créer un corgi

```cards
corgio.create()
```

## Mouvement

```cards
corgio.create().updateSprite(true)
corgio.create().horizontalMovement(true)
corgio.create().verticalMovement(true)
corgio.create().cameraFollow()
```

## Parler

```cards
corgio.create().addToScript("")
corgio.create().bark()
```
