# Animation

## Animations de sprites

Crée et lance des animations sur des sprites. Tu peux créer des animations d'images ou
utiliser des mouvements animés sur un sprite existant.

```cards
animation.runImageAnimation(null, null)
animation.runMovementAnimation(null, "")
animation.stopAnimation(0, null)
```

## Animations avancées

Ces blocs sont disponibles pour les programmes qui utilisent des méthodes d'animation avancées.
Tu peux les trouver en ajoutant l'extension `animation` à ton projet.

```cards
animation.createAnimation(0, 0)
animation.createAnimation(0, 0).addAnimationFrame(null)
animation.attachAnimation(null, null)
animation.setAction(null, 0)
```
