# on Hit Tile

Exécuter du code lorsqu'un sprite touche une tuile mur.

```sig
scene.onHitTile(0, 0, function (sprite) {
	
})
```

Tu peux détecter quand un sprite en mouvement touche une tuile de la scène. Si ton sprite touche une tuile définie comme mur (``wall`` est sur ``ON``), tu peux exécuter du code à ce moment-là. Tu choisis à la fois le type de sprite à surveiller et le type de tuile qu'il va toucher.

Quand un contact avec un mur est détecté, le sprite du type demandé t'est fourni dans le paramètre **sprite** de **handler**.

Un sprite touche un mur lorsque les bords extérieurs de leurs images entrent en contact. Si l'indicateur ``ghost`` d'un sprite est activé, aucun contact avec la tuile mur n'est détecté.

## Paramètres

* **kind** : le type de sprite à surveiller pour un contact avec un mur.
* **type** : le type de tuile mur avec laquelle vérifier le contact.
* **handler** : le code à exécuter lorsque le sprite entre en contact.
>* **sprite** : le sprite qui a touché la tuile mur.

## Exemple #example

Construis un mur de briques avec des tuiles dans la scène. Utilise **A** pour envoyer un sprite ``Ghost`` vers le mur et regarde-le s'arrêter. Quand le bouton **B** est pressé, change la valeur de l'indicateur ``ghost`` et regarde si le fantôme touche le mur ou passe à travers.
