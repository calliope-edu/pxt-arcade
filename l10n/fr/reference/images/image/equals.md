# est égale à

Compare cette image à une autre image pour voir si elles sont identiques.

```sig
image.create(0, 0).equals(null)
```

Chaque pixel de l'image est comparé à celui d'une autre image. Si tous les pixels des deux images sont identiques, les images sont considérées comme « égales ».

## Paramètres

* **other** : l'autre image à laquelle comparer celle-ci.

## Valeur renvoyée

* une valeur [booléenne](/types/boolean) qui est `true` si tous les pixels des deux images sont identiques, ou `false` sinon.
