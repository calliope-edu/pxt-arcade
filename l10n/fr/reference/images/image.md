# image

Le bloc conteneur et éditeur d'une image.

```sig
images._image(null)
```

Un clic sur la fenêtre d'image du bloc ouvre l'éditeur d'images, où tu peux créer une nouvelle image ou modifier l'image actuelle. L'image sert à être attribuée à un sprite ou comme image d'une animation.

## Paramètres

* **image** : l'[image](/types/image) contenue dans le bloc.

## Exemple #example
