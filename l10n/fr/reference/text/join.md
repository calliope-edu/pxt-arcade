# concaténation

Ajoutez une chaîne de texte à une autre pour créer une chaîne plus grande.

```block
let text ="";
text + "string";
```

## Valeur retournée

* [String](/types/string) qui contient tout le texte d'une chaîne, avec le texte d'une autre chaîne qui lui est ajoutée.

## Exemples

### Combiner le texte

Ajoutez le texte de deux chaînes pour créer une nouvelle chaîne.

```blocks
let combinedText = "This text is added to" + "this other text.";
```

### Faire grandir une chaîne

Ajoutez plus de texte à la même chaîne pour la faire grandir.

```blocks
let addedText = "The first part";
addedText = addedText + " plus the second part."; 
```
