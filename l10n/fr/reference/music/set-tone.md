# Définir la tonalité

Indique l'échantillon PCM utilisé pour générer les tonalités.

```sig
music.setTone(null)
```

## #simnote

### ~hint

#### Simulateur

``||music:set tone||`` fonctionne sur le @boardname@. Il se peut qu'il ne fonctionne pas dans le simulateur sur tous les navigateurs.

### ~

## Paramètres

* ``buffer`` : un tampon contenant 1024 échantillons non signés de 10 bits.
