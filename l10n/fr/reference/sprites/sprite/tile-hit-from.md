# tuile touchée depuis

Découvre quel type de tuile le sprite a touché.

```sig
sprites.create(null).tileHitFrom(CollisionDirection.Left)
```

Si ton sprite touche une tuile murale, tu peux savoir de quel type de tuile il s'agit. L'index de la tuile dans la carte de tuiles est retourné.

## Paramètres

* **direction** : la direction dans laquelle vérifier une collision avec un mur : ``left``, ``right``, ``top`` ou ``bottom``.

## Retourne

* un [nombre](/types/number) qui est l'index de la tuile murale en contact avec le sprite.

## Exemple
