# say

Affiche une bulle avec du texte près d'un sprite.

```sig
sprites.create(null).say("")
```

Parfois, tu voudras peut-être afficher un message pour un sprite. Tu peux faire apparaître une bulle contenant du texte à côté du sprite pour qu'il dise quelque chose au joueur.

## Paramètres

* **text** : une [chaîne](/types/string) qui contient le texte de la bulle.
* **millis** : un [nombre](/types/number) facultatif de millisecondes pendant lesquelles la bulle est affichée.
