# set Photon Position

Change la position du photon

```sig
light.createStrip().setPhotonPosition(0)
```

Le photon est replacé à l'index donné. Si l'index est hors limites, il recommence au début.

## Paramètres

* **index** : l'index de la lumière où le photon doit aller
