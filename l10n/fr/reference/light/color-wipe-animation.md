# animation de balayage de couleur

Renvoie une nouvelle instance de l'animation de balayage de couleur.

```
light.colorWipeAnimation
```

## Paramètres

* **rgb** : [nombre](/types/number),

## Exemple

```blocks
forever(() => {
    light.builtin.showAnimationFrame(light.colorWipeAnimation)
})
```
