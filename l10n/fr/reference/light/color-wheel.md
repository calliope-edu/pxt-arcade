# roue des couleurs

Donne une couleur RVB à partir de la valeur d'un angle entre 0 et 255. Pratique
pour faire des calculs avec les couleurs.

```sig
light.colorWheel(0);
```

## Paramètres

* **angle** : [nombre](/types/number),

## Exemple

```blocks
light.builtin.showColor(light.colorWheel(42))
```

```package
light
```
