# Abfolge

Durch den sequentiellen Aufruf einer Funktion nach der anderen kannst du das Programm verschiedene Dinge hintereinander tun lassen.

```python-ignore
doSomething()
doAnotherThing()
```

## Die pass-Anweisung

In Python gibt es das Konzept einer *leeren Anweisung*: das Schlüsselwort `pass` an einer Stelle, an der eine Anweisung erwartet wird. Die `pass`-Anweisung dient als praktischer _Platzhalter_ für eine oder mehrere Anweisungen, die du später ergänzt, um eine Funktionalität fertigzustellen.

```python-ignore
def myUnfinished():
    # Fill in code later to complete this function!
    pass
```
