# Zuweisungsoperator (=)

Verwende ein Gleichheitszeichen, um in einer [Variablen](/blocks/variables/var) eine [Zahl](/types/number), [String](/types/string) oder [Boolean](/types/boolean) zu speichern.

```block
let myNumber = 7
let myString = "Gelb verwirbelt"
let myLogic = true
```

Wenn du das Gleichheitszeichen benutzt, um etwas in einer Variable zu speichern, ist das Gleichheitszeichen ein *Zuweisungsoperator*, und was du speicherst heißt *Wert*. Ein Wert kann ein *Literal* Wert, wie `20` oder `"Träumen" sein`. Oder ein Wert kann eine weitere Variable sein, die kopierert werden soll, ```let neuerWert= alterWert```.

Hier ist ein Beispiel für die Zuweisung von Variablen im Code:

```typescript
let perfekt = 10;
let extra = 1;
let extraPerfekt = perfekt + extra;
```

## ~hint

Den Zuweisungsoperator kann für jedem [Typ](/types) von Variablen verwendet werden. Ein *Typ* ist das Fprmat der Sache eine Variable, wie eine Zahl oder eine Zeichenfolge welche gespeichert werden kann.
