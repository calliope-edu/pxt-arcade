# Variablen

[Ändere](/blocks/variables/assign) (setzt) den Wert einer Variable

```block
let x = 1;
```

Ruft den Wert einer Variablen ab

```block
let x = 1;
let y = x;
```

[Ändere](/blocks/variables/change) den Wert einer Variable

```block
let x = 0;
x+=1;
```
