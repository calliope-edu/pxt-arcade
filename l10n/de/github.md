# GitHub mit MakeCode

[GitHub](https://github.com) ist eine beliebte Webseite, die von Entwicklern zum Hosten und Arbeiten am Code genutzt wird. Mithilfe der GitHub Integration in MakeCode kannst du nahtlos und **frei** deine Programme hosten und mit Freunden daran arbeiten.

Um GitHub nutzen zu können, benötigst du ein [Konto](https://github.com/join) und einen Internetzugang. Du musst nichts anderes wissen als das, was du bereits in MakeCode gelernt hast.

## Repository als Webseiten

MakeCode verwendet [GitHub Seiten](/github/pages) um dein Projektarchiv in eine vollständige Webseite umzuwandeln! Dies ist eine großartige Möglichkeit, dein Portfolio aufzubauen oder ein spielbares Spiel mit Freunden zu teilen.
