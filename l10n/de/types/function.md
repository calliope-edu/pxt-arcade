# Funktion

Eine Funktion ist ein Stück Code, das du in deinem Programm wiederverwenden kannst. Du erstellst eine Funktion mit einer
Funktions-_Definition_, die der Funktion einen Namen gibt und ihren Code enthält. Ein Funktions-_Aufruf_ ist, wenn du eine
Funktion irgendwo in deinem Programm über ihren Namen verwendest.

## Eine Funktion definieren

Eine Funktions-[**Definition**](/types/function/define) ist ein Block, der den Namen der Funktion und ihren Code enthält.

```block
function doSomething() {
}
```

## Eine Funktion aufrufen

Ein Funktions-[**Aufruf**](/types/function/call) ist, wenn du den Code der Funktion an einer Stelle in deinem Programm verwenden möchtest.

```sig
function doSomething() {
}
doSomething();
```
