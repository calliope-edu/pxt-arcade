# Kommandozeilen Oberfläche

Es ist möglich, die Tools aus der **PXT-Befehlszeilenschnittstelle (CLI) **zu verwenden. `PXT` kann:

* JavaScript-Programme bearbeiten, kompilieren oder verteilen.
* Einfach in die meisten IDEs integrieren. Es verfügt über eine integrierte Unterstützung für [Visual Studio Code](/code).
* Einen lokalen Webserver für den Web-Editor laufen lassen.
* Pakete mit JavaScript und/oder C++ erstellen.

Bei der Verwendung der PXT CLI wird davon ausgegangen, dass du über einige Erfahrung mit der Programmierung verfügst und erfordert die Installation von zusätzlichen Tools auf deinem Computer durchführen kannst.
