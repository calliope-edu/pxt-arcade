# Genehmigen von Erweiterungen

Nur genehmigte Erweiterungen sind in den Suchergebnissen des Dialogs `Erweiterungen` verfügbar. GitHub Organisationen oder GitHub Repos können genehmigt werden.

Verbotene Erweiterungen dürfen nicht geladen werden.

## Checkliste

Wann immer du eine Erweiterung zur Genehmigung einreichst, überprüfe bitte, ob du die folgenden Aufgaben erledigt hast:

- [ ] In GitHub wurde eine Version erstellt. Du kannst eine Version der Erweiterung erstellen, wenn du im MakeCode-Editor synchronisierst oder den **pxt bump** cli Befehl verwendest. Das Format **muss** `MAJOR.MINOR.PATCH` sein.
- [ ] Ein Symbolbild **icon.png** ist im Stammverzeichnis verfügbar. Es sollte 300x200 Pixel haben und **kleiner als 100kb** groß sein.
- [ ] Es wurde eine GitHub-Repobeschreibung hinzugefügt, die aussagekräftig genug ist, um bei der Suche nach Erweiterungen zu helfen.
- [ ] Eine Testdatei namens `test.ts` ist vorhanden und kompiliert, wenn **pxt deploy** ausgeführt wird.
- [ ] Die `README.md` Datei enthält API-Dokumentation für die Erweiterungsblöcke.
- [ ] Deine öffentlichen Funktionen und Typen folgen den Benennungskonventionen von [MakeCode](https://makecode.com/extensions/naming-conventions).
