## Start @showdialog

Dieses Tutorial hilft dir, deinem Spiel Levels hinzuzufügen.

Damit Levelwechsel einfacher werden (und du nicht immer wieder denselben
Code schreiben musst), lernen wir außerdem, eine einfache [**_Funktion_**](#funky "Gruppe von Code, die über einen bestimmten Namen aufgerufen werden kann") zu erstellen.

![Levels und Funktionen](/static/skillmap/platformer/platformer4.gif "Und jetzt zu etwas völlig anderem! Und ein bisschen auch dasselbe.")


## Eine Funktion erstellen

Lass uns zuerst eine neue Funktion erstellen!

Funktionen sind Code-Stücke, denen du einen Namen geben und die du
in deinem Programm immer wieder [**_aufrufen_**](#callingYou "über einen Namen in deinen Code einfügen")
kannst. Anders als bei Schleifen kannst du den Code in einer
Funktion immer wieder ausführen, auch wenn du zwischendurch etwas anderes machst.

---


► Klappe im Werkzeugkasten den Bereich **˅ Fortgeschritten** auf und klicke
auf die Kategorie ``||functions: Funktionen||``.

► Klicke auf den Knopf **[ Erstelle eine Funktion... ]**, um deine neue Funktion zu erstellen.

► Klicke in das Textfeld, nenne die Funktion **startNextLevel** und klicke dann auf **Fertig**.

![Eine Funktion benennen](/static/skillmap/platformer/name-function.gif "Sag meinen Namen, sag meinen Namen.")


```blocks
function startNextLevel() {
}
```


## Umbauen Teil 1
Super! Jetzt sollte ein Funktions-Container **startNextLevel**
in deinem Arbeitsbereich sein. Lass ihn uns füllen!

Im Moment steckt der Code zum Starten eines Levels im
Container ``||loops: beim Start||`` – den wollen wir in die Funktion verschieben.

---


► Ziehe den Block ``||scene: setze Tilemap auf [ ]||`` aus ``||loops: beim Start||`` heraus.
Alles, was darunter hängt, kommt mit.

► Setze den ganzen Code-Block in deinen neuen Funktions-Container **startNextLevel**.

**Voilà! Jetzt hast du eine Funktion!**

## Umbauen Teil 2

Hier ist etwas Wichtiges: *Eine Funktion zu bauen bringt nichts, wenn du sie
nicht irgendwo in deinem Programm __aufrufst__.*

Die Funktion, die du gebaut hast, ist nur eine
[**_Definition_**](#defineMe "Erklärung der Bedeutung"),
die dem Computer sagt,
welche Anweisungen er ausführen soll, wenn du **startNextLevel** in deinem Code aufrufst.
Die Definition sagt dem Computer aber nicht, *wann* er diese
Anweisungen ausführen soll.

Lass uns einen Funktionsaufruf in unser Programm einbauen, damit der Computer weiß,
wann er **startNextLevel** ausführen soll.

---

► Ziehe aus der Kategorie ``||functions: Funktionen||`` einen Block
``||functions: Aufruf startNextLevel||`` und hänge ihn ans Ende des
Containers ``||loops: beim Start||``.

---

Teste dein Spiel auf dem Spielbildschirm. Es sollte sich (noch) nicht anders anfühlen
als das Original.

Falls es sich anders anfühlt, sieh dir den Hinweis an
und prüfe, ob dein Code übereinstimmt.

## Variable

**👾 Viele tolle Spiele haben mehr als ein Level 👾**

Wenn wir uns merken wollen, in welchem Level wir sind, und
dieses Level jederzeit abrufen wollen, brauchen wir
eine Variable.

Mit einer Variable können wir den Platzhalter **currentLevel** verwenden,
um Entscheidungen zu treffen, statt für jede Möglichkeit neuen Code zu schreiben.

---


► Um eine neue Variable zu erstellen, gehe ins Menü ``||variables: Variablen||``
und klicke auf ``||variable: Erstelle eine Variable...||``.

► Gib **currentLevel** in das Textfeld ein und klicke auf **OK**.

## Ein Level auswählen Teil 1

Wenn wir für jedes neue Level die Szene ändern wollen (*Spoiler ... das wollen wir!*), dann
brauchen wir etwas Logik, die sich die Variable **currentLevel** ansieht,
bevor die Bühne aufgebaut wird.

Das ist der perfekte Ort für ein weiteres **wenn/dann**-Element!
