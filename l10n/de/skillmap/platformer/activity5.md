## KI-Regeln @showdialog

Der Code dieses Programms lässt Gegner auf den lila **[ ! ]**-Kacheln erscheinen.
Sobald die Gegner erscheinen, laufen sie sofort nach links und bleiben
an einer Wand hängen ... also fügen wir Logik hinzu, damit die Gegner nicht stecken bleiben.

---

**Die Gegner müssen zwei Regeln befolgen:**

1. **Wenn der Gegner gleich gegen eine Wand läuft, versucht er, darüberzuspringen**
2. **Wenn der Gegner doch gegen eine Wand stößt, dreht er um**


---


Jede dieser Regeln hat eine *Bedingung* und eine *Aktion*.

Wenn die Bedingung erfüllt ist, passiert die Aktion.
Wir müssen Code schreiben, der ständig jede dieser Bedingungen prüft.

## Schleifen Teil 1

Zuerst brauchen wir einen Container **wenn Spielupdate**, der jedes Mal Code auslöst,
wenn sich im Spiel etwas ändert. Darin brauchen wir eine Schleife, die
jeden Gegner einzeln überprüft.

---


► Ziehe einen Block ``||game:wenn Spielupdate||`` heraus und lege ihn in den Arbeitsbereich.

► Hänge einen Block ``||loops: für Element [Wert] von [list]||`` in den
Container **wenn Spielupdate**.

```blocks
let list: number[] = [];
game.onUpdate(function () {
    for (let value of list) {
    }
})
```

## Springen Teil 1

Fangen wir mit dem Code für unsere erste Regel an:

> 1. **Wenn der Gegner gleich gegen eine Wand läuft, versucht er, darüberzuspringen**

---


► Wir müssen prüfen, **ob** etwas wahr ist. Ziehe dafür
einen Logik-Container ``||logic: wenn <wahr> dann||`` in den leeren Container **wenn Spielupdate**.

► Stelle jetzt sicher, dass der Gegner nicht schon springt, indem du
``||logic: <wahr>||`` im leeren Kopf von **wenn/dann** durch ``||scene: wenn [mySprite] Wand trifft [links]||`` ersetzt.

► Ersetze ``||variables(noclick): mySprite||`` durch ``||variables(noclick): Wert||``, damit
der aktuelle Gegner geprüft wird.

► Ändere **links** zu **unten**, um zu prüfen, ob die Unterseite des Sprites auf dem Boden ist.


```blocks
game.onUpdate(function () {
    for (let value of sprites.allOfKind(SpriteKind.Enemy)) {
        if (value.isHittingTile(CollisionDirection.Bottom)) {

        }
    }
})
```

## Springen Teil 2

Jetzt wissen wir, dass der Gegner auf dem Boden ist. Es gibt zwei Bedingungen,
bei denen er springen muss:
 - Wenn er sich nach links bewegt und links eine Wand ist
 - Wenn er sich nach rechts bewegt und rechts eine Wand ist

Ob einer dieser Fälle eintritt, finden wir mit einer neuen **wenn/dann**-Anweisung heraus.

---


► Ziehe einen weiteren Block ``||logic:wenn <wahr> dann||`` heraus und lege ihn in den
leeren Block, der schon in der Schleife **für Element** ist.

► Um zu prüfen, ob zwei Dinge gleichzeitig wahr sind (Bewegung nach links **und** Wand links),
ziehe einen Block ``||logic: < > und < >||`` hinein, um das Argument ``||logic:<wahr>||``
in der neuen **wenn/dann**-Anweisung zu ersetzen.

► Setze in die rechte Lücke (rechts vom **und**) einen Block ``||scene: Kachel [links] von [mySprite] ist [ ]||``

► Ersetze ``||variables(noclick): mySprite||`` durch ``||variables(noclick): Wert||`` und ersetze die leere
Kachel durch die **[X]**.

► Setze links vom **und** einen Block ``||logic: [0] [<] [0]||`` ein.

---

Damit machen wir im nächsten Schritt weiter.


```blocks
game.onUpdate(function () {
    for (let value of sprites.allOfKind(SpriteKind.Enemy)) {

            if (0 < 0 && value.tileKindAt(TileDirection.Left, myTiles.tile1)) {

})
```

## Springen Teil 3

Wir prüfen schon, ob die nächste Kachel links eine Wand ist,
aber das ist nur wichtig, wenn sich der Gegner nach links bewegt.

Lass uns Code hinzufügen, der prüft, ob sich der Gegner nach links bewegt.

---

Im Arcade-System ist links negativ und rechts positiv. Um zu prüfen, ob sich das
Sprite nach links bewegt, musst du sicherstellen, dass seine Geschwindigkeit in x-Richtung
negativ ist.

► Nimm einen Argument-Block ``||sprites: [mySprite] [x]||`` und ersetze damit die
erste **0** in ``||logic: [0] [<] [0]||``.

► Ersetze ``||variables(noclick): mySprite||`` durch ``||variables(noclick): Wert||`` und ersetze
**x** durch **vx (Geschwindigkeit x)**.



```blocks
game.onUpdate(function () {
    for (let value of sprites.allOfKind(SpriteKind.Enemy)) {
        if (value.isHittingTile(CollisionDirection.Bottom)) {
            if (value.vx < 0 && value.tileKindAt(TileDirection.Left, myTiles.tile1)) {
            }
        }
    }
})
```


## Springen Teil 6

Wenn der Computer an dieser Stelle im Code ankommt, ist es Zeit für den
Gegner zu springen.

---


► Hänge in die gerade gebaute **wenn/dann**-Anweisung einen Block ``||sprites:setze [mySprite] [x] auf [0]||``.

► Ersetze ``||variables(noclick): mySprite||`` durch ``||variables(noclick): Wert||`` und ersetze
``||sprites: x||`` durch ``||sprites: vy (Geschwindkeit y)||``.

► Ändere **0** auf **-150**.


```blocks
game.onUpdate(function () {
    for (let value of sprites.allOfKind(SpriteKind.Enemy)) {
        if (value.isHittingTile(CollisionDirection.Bottom)) {
            if (value.vx < 0 && value.tileKindAt(TileDirection.Left, myTiles.tile1)) {
                value.vy = -150
            }
    }
})
```


## Springen Teil 7

Als Nächstes fügen wir Code hinzu, der dasselbe nach rechts macht.

---


► Klicke zweimal auf das **⊕** unten an der innersten **wenn/dann**-Anweisung,
die wir gerade fertiggestellt haben, um einen **ansonsten**- und dann einen **sonst wenn**-Zweig hinzuzufügen.

► Dupliziere die ganze **und**-Anweisung und lege das Duplikat in den
Kopf des **sonst wenn**-Zweigs.

► Ändere im neuen Zweig **<** zu **>** und **links** zu **rechts**.

► Dupliziere den Block ``||sprites:setze [Wert] [vy (Geschwindkeit y)] auf [-150]||``
und hänge die Kopie in die leere **sonst wenn**-Anweisung.

► Mit dieser **wenn/sonst wenn**-Anweisung sind wir jetzt fertig, also kannst du auf das
**⊖** neben dem leeren **ansonsten**-Zweig klicken, um ihn aus dem Block zu entfernen.



```blocks
game.onUpdate(function () {
    for (let value of sprites.allOfKind(SpriteKind.Enemy)) {
        if (value.isHittingTile(CollisionDirection.Bottom)) {
            if (value.vx < 0 && value.tileKindAt(TileDirection.Left, myTiles.tile1)) {
                value.vy = -150
            } else if (value.vx > 0 && value.tileKindAt(TileDirection.Right, myTiles.tile1)) {
                value.vy = -150
            }
        }
    }
})
```


## Von Wänden abprallen Teil 1

## Von Wänden abprallen Teil 2

Zum Schluss fügen wir Code hinzu, damit die Gegner nach rechts umdrehen, wenn sie
nach links gelaufen sind, und nach links, wenn sie nach rechts gelaufen sind.

---


► Erstelle zwei Duplikate von einem der Blöcke ``||sprites:setze [Wert] [vy (Geschwindkeit y)] auf [-150]||`` aus dem ursprünglichen **wenn/dann**-
Zweig und hänge je eines in die leeren **sonst wenn**-Zweige.

► Ändere im Block **setze Wert** im ersten **sonst wenn**-Zweig
(**sonst wenn <wenn Wert Wand trifft links> dann**)
**vy (Geschwindkeit y)** zu **vx (Geschwindigkeit x)** und **-150** zu **30**.

► Ändere im Block **setze Wert** im zweiten **sonst wenn**-Zweig
(**sonst wenn <wenn Wert Wand trifft rechts> dann**)
**vy (Geschwindkeit y)** zu **vx (Geschwindigkeit x)** und **-150** zu **-30**.


```blocks
game.onUpdate(function () {
    for (let value of sprites.allOfKind(SpriteKind.Enemy)) {
        if (value.isHittingTile(CollisionDirection.Bottom)) {
            if (value.vx < 0 && value.tileKindAt(TileDirection.Left, myTiles.tile1)) {
                value.vy = -150
            } else if (value.vx > 0 && value.tileKindAt(TileDirection.Right, myTiles.tile1)) {
                value.vy = -150
            }
        } else if (value.isHittingTile(CollisionDirection.Left)) {
            value.vx = 30
        } else if (value.isHittingTile(CollisionDirection.Right)) {
            value.vx = -30
        }
    }
})
```
