# Empfohlener Browser für Windows

Wir empfehlen [Microsoft Edge](https://www.microsoft.com/en-us/windows/microsoft-edge) wenn du Windows 10 verwendest aber Benutzer von Windows 7 oder höher können [Microsoft Edge beta](https://www.microsoftedgeinsider.com/en-us/download/) oder aktuelle Versionen von [Mozilla Firefox](https://www.mozilla.org/en-US/firefox/new/), [Google Chrome](https://www.google.com/chrome/), oder [Opera](https://www.opera.com)verwenden.

Bitte lese [hier](/browsers/technical), um technische Informationen darüber zu erhalten, welche Browser unterstützt werden oder [hier](/browsers), um zu überprüfen, welche Version du verwendest.
