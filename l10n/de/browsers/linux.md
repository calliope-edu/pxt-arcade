# Empfohlener Browser für Linux

Wenn du Linux verwendest wird empfohlen, [Mozilla Firefox](https://www.mozilla.org/en-US/firefox/new/) oder [Google Chrome](https://www.google.com/chrome/) zu verwenden.

Bitte lese [hier](/browsers/technical), um technische Informationen darüber zu erhalten, welche Browser unterstützt werden oder [hier](/browsers), um zu überprüfen, welche Version du verwendest.
