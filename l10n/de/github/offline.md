# Offline für GitHub-Erweiterungen

Wenn du deine Erweiterung ohne Internet nutzen möchtest (offline), musst du deine Erweiterung in einer Datei speichern und mit deinen Benutzern teilen.

## Wie man exportiert

* Öffne dein Erweiterungsprojekt
* Wechsele zur JavaScript-Ansicht,
* Öffnen der GitHub-Ansicht
* klicke auf **Für Offline-Gebrauch speichern**

Die exportierte Datei sollte von deinen Benutzern importiert werden.
