# GitHub Token

Du kannst einen **GitHub Entwicklertoken ** verwenden, um dich bei GitHub anzumelden, wenn du die** Microsoft MakeCode mit GitHub App ** nicht verwenden möchtest. Der Token ist gültig für den Zugriff auf Repositories in allen Organisationen.

## Was ist ein Token?

Ein Token ist eine spezielle Nummer, die dir zugewiesen ist, um deinen Zugriff auf GitHub zu erlauben.

### ~ hint

#### Token sind geheim

Behandle Token wie Passwörter!

### ~

Du kannst eine weitere [detaillierte](https://help.github.com/en/github/authenticating-to-github/creating-a-personal-access-token-for-the-command-line) Beschreibung über GitHub Zugriffstoken lesen.

## Wie man ein GitHub Entwicklertoken bekommt

1. Navigiere zu https://github.com/settings/tokens/new.
2. Setze einen Namen, der klar erklärt, warum du diesen Token benötigst.
3. Wähle den **repo** Bereich aus, je nachdem, welche Repos du hier bearbeiten möchtest.
4. Klicke auf **generate token**, kopiere ihn und füge ihn in den MakeCode-Dialog ein.

### ~ hint

#### Öffentlicher Zugriff

Wähle für **öffentliche Repositorys**den `public_repo-` und `Workflowbereich` aus.
