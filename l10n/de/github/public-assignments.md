# Öffentliche Aufgaben

Diese Seite beschreibt, wie öffentliche Aufgaben über GitHub verwaltet werden. Jede Aufgabe ist ein **öffentliches Repository** unter dem Konto des Kursteilnehmers.

Lass uns die Aktionen für eine **Hausaufgabe** veranschaulichen.

## Schritt 1: Schüler erstellen ein neues öffentliches Repository

Im MakeCode-Editor erstellt der Kursteilnehmer ein **öffentliches** Repository für die Aufgabe, die unter seinem Konto gehostet wird. Alle Kursteilnehmer sollten das Repository mit dem gleichen Namen wie die Aufgabe benennen (z. B. "Hausaufgaben" in diesem Beispiel).

## Schritt 2: Schüler Änderungs-, Commit-, Push-Zyklus

Es ist Zeit zu arbeiten! Schüler erledigen ihre Arbeit und verwenden die **commit & Taste ** um sie zu speichern. Es ist eine gute Idee, sie dazu zu ermutigen, einen commit zu erstellen, wann immer sie das Gefühl haben, dass sie Fortschritte gemacht haben und dass sie immer eine sinnvolle Beschreibung der Änderungen hinzufügen.

## Schritt 3: Der Lehrer überprüft den Commit-Verlauf

Der Lehrer kann den [MakeCode GitHub Explorer](https://makecode.com/github-explorer) verwenden, um einfach die Repositories eines Benutzers zu durchsuchen. Bei Bedarf kann der Lehrer auch den gesamten Verlauf des Projekts auf GitHub einsehen.
