# GitHub FAQ

## Mein Repository sieht leer aus

Vergiss nicht deinen Code mit [commit](/github/commit) zu übertragen! Du musst zur GitHub-Ansicht wechseln und auf **Commit & push** drücken um deine Änderungen in GitHub zu speichern.

## Gibt es die Möglichkeit einer einfachen Überprüfung aller Repositories eines Benutzers?

Ja, verwende den [Explorer](/github/explorer).

## Meine Organisation lässt die App "Microsoft MakeCode for GitHub" nicht zu?

Wenn du unsere GitHub-App nicht genehmigen kannst, verwende stattdessen einen Entwicklertoken im Anmeldedialogfeld.
