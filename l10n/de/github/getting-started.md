# Erste Schritte

Lass uns GitHub entdecken, indem du ein übliches Nutzungsszenario erklärst: Du bearbeitest dein eigenes Projekt und nutzst GitHub, um deine Änderungen zu speichern.

### #youtube

https://youtu.be/J-pI1sEWPV0

## Schritt 1 - Erstellen eines Repositorys

Ein **Repository ** wird verwendet, um ein einzelnes Projekt zu organisieren. Repositories enthalten alle Dateien, die für deine MakeCode-Projekte benötigt werden.

1. Öffne den [Editor](@homeurl@), erstelle ein neues Projekt
2. Klicke auf den **GitHub** Button neben **Speichern**.
3. Wähle einen guten Namen und eine gute Beschreibung (das hilft bei der Suche im Internet!).

### ~hint

#### Anmelden

Wenn du dich noch nicht mit GitHub angemeldet hast, wirst du zur GitHub Anmeldeseite weitergeleitet. Bei der ersten Verwendung von MakeCode wirst du auch gebeten, die **Microsoft MakeCode mit GitHub** App zu autorisieren. Dadurch wird MakeCode mit unserer GitHub-App integriert.

Fortgeschrittene Benutzer können ein [Entwicklertoken](/github/token) verwenden, sodass sie direkt mit GitHub arbeiten können, ohne sich mit der App anmelden zu müssen.

Wenn du noch kein GitHub Konto hast, musst du dich zuerst für eines [registrieren](/github/sign-up).

## Schritt 2 - Erstellen von Codeänderungen

Leg los und verändere einige Stellen Code in deinem Projekt.

## Schritt 3 - Überprüfe deine Änderungen

Wenn du Änderungen im Code-Editor vornimmst, wirst du feststellen, dass auf der **GitHub** Schaltfläche ein Pfeil nach oben angezeigt wird. Der Pfeil bedeutet, dass Änderungen auf deinem Computer gespeichert sind und diese auf GitHub gespeichert werden müssen. Klicke auf diese Schaltfläche, um die **GitHub Ansicht ** zu öffnen.

Du siehst die Liste der geänderten Dateien und deren Unterschiede, oder **diffs**. Ein **diff** wird von Entwicklern verwendet, um eine formatierte Anzeige der Unterschiede zwischen zwei Texten zu beschreiben (lies dazu [diffs ](/github/diff)). Schaue dir diff sorgfältig an, du siehst so, welche Zeilen du hinzugefügt, gelöscht oder geändert hast.

### ~ hint

#### Lokale Änderungen zurücksetzen

Wenn dir einige deiner Änderungen nicht gefallen, kannst du auf **Zurückkehren** neben der geänderten Datei klicken. Es erlaubt dir, alle Änderungen in dieser Datei rückgängig zu machen und sie auf den Inhalt der vorherigen Übertragung zurückzusetzen.

### ~

## Schritt 4 - Commit & Push-Änderungen

Klicke auf die Schaltfläche **commit & push-Änderungen**, um diese in GitHub zu speichern. Dies wird einen neuen **commit** in deinem Repository erstellen. A **commit** is a bundled set of changes that can be uploaded to GitHub (read more about [commits](/github/commit)).


Das war's! Jedes Mal, wenn du Änderungen an deinem Code behalten möchtest, wiederhole die Schritte 2, 3 und 4!
