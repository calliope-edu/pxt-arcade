# GitHub-Seiten

MakeCode verwendet [GitHub Seiten](https://pages.github.com/) um dein Projektarchiv in eine vollständige Webseite umzuwandeln!

Die **Github Pages** Website zeigt entweder die gerenderte `README.md` Datei an oder das kompilierte Spiel, das im Vollbildmodus für Arcade läuft.

## Benutzerdefinierte Seiten

Standardmäßig überschreibt MakeCode die unterstützenden Dateien, um das Seitenprojekt in jeder Version zu rendern. Du kannst dieses Verhalten deaktivieren, indem du diesen Code in `pxt.json` zufügst:

```
disableTargetTemplateFiles: true
```
