# Commit

Auf GitHub werden **gespeicherte Änderungen** **commits**genannt. Jeder Commit hat eine zugehörige Commit-Nachricht, eine Beschreibung, warum eine bestimmte Änderung vorgenommen wurde. Commit-Nachrichten erfassen den Verlauf Ihrer Änderungen, damit andere Beitragende verstehen, was Sie getan haben und warum.

## Commit & push

Wenn du Änderungen im Code-Editor vornimmst, wirst du feststellen, dass auf der **GitHub-Taste** ein Pfeil nach oben angezeigt wird. Der Pfeil bedeutet, dass es **lokale** Änderungen gibt. Sie werden auf deinem Computer gespeichert und müssen auf GitHub gespeichert werden. Klicke auf diesen Button, um die **GitHub Ansicht zu öffnen**.

Die GitHub Ansicht enthält die [diffs](/github/diff) die jede **lokale** Änderung repräsentiert. Wenn die Änderungen gut aussehen, klicke auf **commit & push-Änderungen** um einen **commit** und **push** zu GitHub zu erstellen. Sobald der Commit übertragen wurde, ist dein Code sicher in GitHub gespeichert!

## Überprüfung & rückgängig machen

It's good practice to **review** your **local** changes before committing; just like you review your answer sheet before turning in a test. Wenn du Änderungen findest, die nicht korrekt sind, kannst du sie sofort beheben und mit **revert** zurücksetzen oder sie mit **commit** zu übertragen, damit du später alle Korrekturen machen kannst.
