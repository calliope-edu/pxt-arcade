# Klassenzimmer

Diese Seite beschreibt verschiedene Möglichkeiten, mit der GitHub Integration Aufgaben zu erstellen und zu sammeln. Die Beschreibung hier setzt voraus, dass alle Schüler zuerst einen Account auf https://github.com registrieren können.

## Zuweisungen als Repositories

Die Kursteilnehmer können für jede Aufgabe neue öffentliche oder private Repositorys erstellen. Repositories bieten vollständige Rückverfolgbarkeit der Änderungen, Kollaborationsfunktionen und präzise Zugriffssteuerung für die Lehrer.

Es gibt einige verschiedene Möglichkeiten um Repositories zu verwenden. In der Reihenfolge der Komplexität:

* [öffentliche Zuweisungen](/github/public-assignments) mithilfe öffentlicher Repositorys. Einfach einzurichten, aber der Code ist öffentlich.
* [Private Zuweisungen](/github/private-assignments) mit privaten Repositories. Weitere Einrichtungsschritte, aber Code ist nur für den Schüler und den Lehrer sichtbar.
* [GitHub Klassenzimmer ](https://classroom.github.com) bietet ein integriertes Klassenzimmer-Management-System, das viele Schritte zur Erstellung des Projektarchivs automatisiert.
