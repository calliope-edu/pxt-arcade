# reset

Setze das Board zurück und starte das Programm von vorne.

```sig
control.reset()
```

Alles, was das Programm mit dem Board gemacht hat, wird auf den Zustand vor dem
Programmstart zurückgesetzt. Das Programm beginnt wieder von vorne.

## Beispiel #example

Setze das Board zurück und beginne von vorne.

```blocks
control.reset()
```
