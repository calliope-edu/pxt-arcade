# Eigenschaften

Eigenschaften, die die Flugbahn des Pfeils steuern.

## angle

Der Wurfwinkel.

### abrufen

```block
let myDart: Dart = null
let angle = myDart.angle
```

### festlegen

```block
let myDart: Dart = null
myDart.angle = 10
```

## pow

Die Wurfkraft, die auf den Pfeil wirkt.

### abrufen

```block
let myDart: Dart = null
let power = myDart.pow
```

### festlegen

```block
let myDart: Dart = null
myDart.pow = 50
```

## Schwerkraft

### festlegen

