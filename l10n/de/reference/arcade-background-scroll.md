# Erweiterung Arcade Background Scroll

Dies ist eine Erweiterung für [MakeCode Arcade](arcade.makecode.com), die Blöcke zum Scrollen und Wiederholen von Hintergrundbildern hinzufügt.

Damit kannst du auch einen Parallaxeneffekt erzeugen, indem du mehrere Ebenen unterschiedlich schnell scrollst.

Quelle: [microsoft/arcade-background-scroll](https://github.com/microsoft/arcade-background-scroll/tree/v0.1.2) (v0.1.2)

```package
arcade-background-scroll
```
