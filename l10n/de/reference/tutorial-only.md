# Blöcke nur für Tutorials

## Über Blöcke nur für Tutorials

Die Blöcke, die du hier siehst, sind eigene Blöcke, die speziell für dieses Tutorial entwickelt wurden. Sie vereinfachen die Tutorial-Schritte und machen es leichter, dein Spiel beim Lernen zu bauen.

## Was machen sie?

Diese Tutorial-Blöcke sollen:

- komplexe Spielmechaniken in einfach zu nutzende Blöcke verpacken
- deinen Code übersichtlich und leicht verständlich halten
- dir helfen, dich auf die wichtigsten Konzepte zu konzentrieren
- die Tutorial-Schritte klarer und einfacher machen

## So verwendest du sie

Folge einfach den Anweisungen im Tutorial! Während du das Tutorial durcharbeitest, lernst du:

1. **Was jeder Block macht** - Das Tutorial erklärt den Zweck jedes Blocks
2. **Wann du sie verwendest** - Du siehst praktische Beispiele im Zusammenhang
3. **Wie sie zusammenarbeiten** - Baue dein Spiel Schritt für Schritt

## Mach mit dem Tutorial weiter

Diese Blöcke gibt es nur in diesem Tutorial. Um mehr darüber zu erfahren, was jeder Block macht und wie du ihn verwendest, folge einfach weiter den Tutorial-Schritten!
