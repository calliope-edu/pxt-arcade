# verbinde

Füge eine Textzeichenfolge zu einer anderen hinzu, um eine größere Zeichenfolge zu erhalten.

```block
let text ="";
text + "Zeichenkette";
```

## Rückgabewert

* eine [Zeichenkette](/types/string), die den gesamten Text aus einer Zeichenkette enthält, wobei der Text aus einer anderen Zeichenkette hinzugefügt wird.

## Beispiele

### Text kombinieren

Fügt den Text von zwei Strings zusammen, um eine weitere neue Zeichenkette zu erstellen.

```blocks
let combinedText = "Dieser Text wird zu" + "diesem Text hinzugefügt.";
```

### Vergößert eine Zeichenkette

Fügt mehr Text zu einem bestehender Zeichenkette hinzu, damit diese größer wird.

```blocks
let addedText = "Der erste Teil";
addedText = addedText + " plus den zweiten Teil."; 
```
