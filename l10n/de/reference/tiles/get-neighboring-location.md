# Nachbarposition abrufen

Ruft die Position einer Kachel neben dieser ab.

```sig
tiles.getTileLocation(0, 0).getNeighboringLocation(CollisionDirection.Top)
```

Eine Nachbarkachel liegt direkt `left` (links), `right` (rechts), `top` (oben) oder `bottom` (unten) neben der aktuellen Kachel. Du kannst die Seite der Nachbarkachel angeben, deren Position du haben möchtest.

## Parameter

* **direction**: die Richtung, in der die Nachbarkachel von dieser Kachel aus liegt. Zur Auswahl stehen `left`, `right`, `top` oder `bottom`.

## Rückgabewert

* ein [Positions](/reference/tiles/location)-Objekt für die Nachbarkachel.

## Beispiel #example

Lass ein Donut-Sprite über benachbarte Kacheln einer Tilemap im Kreis wandern.

```blocks
let nextSpot: tiles.Location = null
let rotation = 0
tiles.setCurrentTilemap(tilemap`level1`)
let meinSprite = sprites.create(img`
    . . . . . . b b b b a a . . . . 
    . . . . b b d d d 3 3 3 a a . . 
    . . . b d d d 3 3 3 3 3 3 a a . 
    . . b d d 3 3 3 3 3 3 3 3 3 a . 
    . b 3 d 3 3 3 3 3 b 3 3 3 3 a b 
    . b 3 3 3 3 3 a a 3 3 3 3 3 a b 
    b 3 3 3 3 3 a a 3 3 3 3 d a 4 b 
    b 3 3 3 3 b a 3 3 3 3 3 d a 4 b 
    b 3 3 3 3 3 3 3 3 3 3 d a 4 4 e 
    a 3 3 3 3 3 3 3 3 3 d a 4 4 4 e 
    a 3 3 3 3 3 3 3 d d a 4 4 4 e . 
    a a 3 3 3 d d d a a 4 4 4 e e . 
    . e a a a a a a 4 4 4 4 e e . . 
    . . e e b b 4 4 4 4 b e e . . . 
    . . . e e e e e e e e . . . . . 
    . . . . . . . . . . . . . . . . 
    `, SpriteKind.Player)
meinSprite.x = meinSprite.x - meinSprite.width
game.onUpdateInterval(1000, function () {
    if (rotation == 0) {
        nextSpot = meinSprite.tilemapLocation().getNeighboringLocation(CollisionDirection.Right)
    } else if (rotation == 1) {
        nextSpot = meinSprite.tilemapLocation().getNeighboringLocation(CollisionDirection.Bottom)
    } else if (rotation == 2) {
        nextSpot = meinSprite.tilemapLocation().getNeighboringLocation(CollisionDirection.Left)
    } else {
        nextSpot = meinSprite.tilemapLocation().getNeighboringLocation(CollisionDirection.Top)
    }
    meinSprite.setPosition(nextSpot.x, nextSpot.y)
    rotation += 1
    if (rotation > 3) {
        rotation = 0
    }
})
```
