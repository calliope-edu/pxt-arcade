# Corgio

Eine kleine Erweiterung, die dir hilft, ein Plattformspiel mit einem Corgi zu erstellen.

## Corgi erstellen

```cards
corgio.create()
```

## Bewegung

```cards
corgio.create().updateSprite(true)
corgio.create().horizontalMovement(true)
corgio.create().verticalMovement(true)
corgio.create().cameraFollow()
```

## Sprechen

```cards
corgio.create().addToScript("")
corgio.create().bark()
```
