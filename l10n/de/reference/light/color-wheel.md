# color Wheel

Gibt eine RGB-Farbe für einen Winkelwert zwischen 0 und 255 zurück. Nützlich,
um mit Farben zu rechnen.

```sig
light.colorWheel(0);
```

## Parameter

* **angle**: eine [Zahl](/types/number),

## Beispiel

```blocks
light.builtin.showColor(light.colorWheel(42))
```

```package
light
```
