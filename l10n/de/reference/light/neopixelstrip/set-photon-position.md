# Photonen-Position festlegen

Ändere die Position des Photons

```sig
light.createStrip().setPhotonPosition(0)
```

Das Photon wird an den angegebenen Index versetzt. Liegt der Index außerhalb des Bereichs, wird er umgebrochen (fängt wieder von vorne an).

## Parameter

* **index**: Index des Lichts, zu dem das Photon wandert
