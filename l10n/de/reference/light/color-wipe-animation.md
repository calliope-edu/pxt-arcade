# color Wipe Animation

Gibt eine neue Instanz der Farbwisch-Animation zurück.

```
light.colorWipeAnimation
```

## Parameter

* **rgb**: eine [Zahl](/types/number),

## Beispiel

```blocks
forever(() => {
    light.builtin.showAnimationFrame(light.colorWipeAnimation)
})
```
