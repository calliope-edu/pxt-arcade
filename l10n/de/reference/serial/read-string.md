# Zeichenfolge lesen

Lies die gepufferten seriellen Daten als Zeichenfolge.

```sig
serial.readString();
```

## Rückgabewert

* eine [Zeichenfolge](/types/string) mit den Eingaben von der seriellen Schnittstelle. Die Zeichenfolge ist leer, wenn keine Daten verfügbar sind.
