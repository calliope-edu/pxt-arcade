# Puffer lesen

Lies die gepufferten seriellen Daten als Puffer.

```sig
serial.readBuffer();
```

## Rückgabewert

* ein [Puffer](/types/buffer) mit den Eingaben von der seriellen Schnittstelle. Der Puffer ist leer, wenn keine Daten verfügbar sind.
