# setze Ton

Legt das PCM-Sample fest, mit dem Töne erzeugt werden.

```sig
music.setTone(null)
```

## #simnote

### ~hint

#### Simulator

``||music:setze Ton||`` funktioniert auf dem @boardname@. Im Simulator funktioniert es eventuell nicht in jedem Browser.

### ~

## Parameter

* ``buffer``: ein Puffer mit 1024 vorzeichenlosen 10-Bit-Samples.
