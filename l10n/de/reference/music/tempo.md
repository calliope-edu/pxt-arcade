# Tempo

Finde das Tempo (die Geschwindigkeit) der Musik heraus, die gerade gespielt wird.

```sig
music.tempo()
```

## #example

## Rückgabewert

* eine [Zahl](/types/number), die die Anzahl der Schläge pro Minute angibt (Anzahl der
  Schläge in einer Minute der Musik, die der @boardname@ gerade spielt).
