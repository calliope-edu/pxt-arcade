# setze Tempo 

Lass die gespielte Musik schneller oder langsamer laufen, indem du das Tempo (die Geschwindigkeit) änderst.

```sig
music.setTempo(60)
```

## #simnote
### ~hint

#### Simulator

``||music:setze Tempo||`` funktioniert auf dem @boardname@. Im Simulator funktioniert es eventuell nicht in jedem Browser.
### ~

## Parameter

* ``bpm`` ist eine [Zahl](/types/number), die die gewünschten _Schläge pro Minute_ angibt. So schnell
soll der @boardname@ die Musik spielen.

## Beispiel #example

Setze das Musiktempo auf 240 Schläge pro Minute.

```blocks
music.setTempo(240)
```
