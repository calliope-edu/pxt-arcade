# Bild

Der Container- und Editor-Block für ein Bild.

```sig
images._image(null)
```

Wenn du auf das Bildfenster im Block klickst, öffnet sich der Bildeditor, in dem du ein neues Bild erstellen oder das aktuelle bearbeiten kannst. Das Bild kannst du einem Sprite zuweisen oder als Einzelbild in einer Animation verwenden.

## Parameter

* **image**: das [Bild](/types/image), das der Block enthält.
