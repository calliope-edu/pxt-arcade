# ist gleich

Vergleiche dieses Bild mit einem anderen Bild, um festzustellen, ob sie gleich sind.

```sig
image.create(0, 0).equals(null)
```

Jedes Pixel des Bildes wird mit dem anderen Bild verglichen. Wenn alle Pixel in beiden Bildern identisch sind, gelten die Bilder als „gleich“.

## Parameter

* **other**: das andere Bild, mit dem dieses verglichen wird.

## Rückgabewerte

* ein [boolescher](/types/boolean) Wert, der `true` ist, wenn alle Pixel der beiden Bilder identisch sind, andernfalls `false`.
