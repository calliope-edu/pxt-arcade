# arcade-mini-menu

Füge Menüs zu deinem MakeCode-Arcade-Spiel hinzu

Dies ist eine Erweiterung für [Microsoft MakeCode Arcade](https://arcade.makecode.com/), mit der du Menüs für dein Arcade-Spiel erstellen kannst!

Einige ihrer Funktionen:

1. Menüs, die als Sprites verwendet werden können (mit allen Blöcken der Kategorie Sprites)
2. Unterstützung für Text und Symbole
3. Automatisches Scrollen bei wenig Platz
4. Flexible Menü-Layouts: eine Spalte, eine Zeile oder ein x-y-Raster
5. Viele Stiloptionen, damit das Menü zum Aussehen deines Spiels passt
