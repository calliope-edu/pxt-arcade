# Aktion setzen

Starte eine Animationsaktion, die an einen Sprite angehängt ist.

```sig
animation.setAction(null, 0)
```

An einen Sprite angehängte Animationen haben unterschiedliche Aktionen. Die Animation wird mit einer Aktionsart wie ``Walking`` oder ``Jumping`` [erstellt](/reference/animation/create-animation). So kannst du jederzeit verschiedene Animationen aktivieren, indem du einfach eine neue Aktion setzt.

## Parameter

* **sprite**: der Sprite, für den eine Animationsaktion gestartet wird.
* **action**: die Animationsaktion, die auf dem Sprite gestartet wird.
