# Animation erstellen

Erstelle ein Animationsobjekt, das an einen Sprite angehängt wird.

```sig
animation.createAnimation(0, 0)
```

Ein Animationsobjekt enthält Einzelbilder, die nacheinander angezeigt werden. Direkt nach dem Erstellen ist die Animation leer. Es werden Bilder hinzugefügt, bis die Animation eine vollständige Aktion zeigt. Die Animation ist mit ihrer Aktion verknüpft. Eine Aktion ist eine Tätigkeit, die einen Wert erhält, etwa ``Walking``, ``Flying``, ``Running`` oder ``Jumping``. 

Aktionen werden in einer Aufzählung namens ``ActionKind`` festgelegt und beim Erstellen der Animation ausgewählt. Neue Aktionen fügst du hinzu, indem du in JavaScript einen neuen Wert für ``ActionKind`` einträgst oder in der Aktions-Auswahlliste von ``||animation:create animation||`` ``Add a new action...`` wählst.

```typescript-ignore
enum ActionKind {
    Walking,
    Idle,
    Jumping
}
```

Jedes Bild einer Animation wird eine bestimmte Zeit lang angezeigt. Diese wird im **interval** als Anzahl von Millisekunden festgelegt.

## Parameter

* **action**: eine Aktion, mit der die Animation verknüpft wird, zum Beispiel ``Walking`` oder ``Jumping``.
* **interval**: eine [Zahl](/types/number), die angibt, wie viele Millisekunden jedes Bild der Animation angezeigt wird.

## Rückgabewert

* eine [Animation](/types/animation), die später an einen Sprite angehängt wird.
