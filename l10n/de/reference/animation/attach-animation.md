# Animation anhängen

Hänge eine Animation an einen Sprite an.

```sig
animation.attachAnimation(null, null)
```

Eine Animation muss an einen Sprite angehängt werden, bevor sie aktiviert werden kann. Die Animation läuft im Bildbereich des Sprites. Wenn sich der Sprite bewegt, bewegt sich die Animation mit und wird dort angezeigt, wo sich der Sprite gerade befindet.

Du kannst mehrere Animationen an einen Sprite anhängen. Es ist immer nur eine aktiv, und zwar die, deren [Aktion](/reference/animation/set-action) am Sprite gesetzt ist.
