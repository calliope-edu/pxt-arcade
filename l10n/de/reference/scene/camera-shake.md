# Kamera wackeln

Lass die Kameraansicht wackeln, um einen Erschütterungseffekt zu erzeugen.

```sig
scene.cameraShake(4, 1000)
```

## Parameter

* **amplitude**: eine [Zahl](/types/number): die maximale Verschiebung der Kamera.
* **duration**: eine [Zahl](/types/number): die Dauer in Millisekunden

## Beispiel #example

Lass die Kameraansicht 1 Sekunde lang wackeln.

```blocks
scene.cameraShake(4, 1000)
```
