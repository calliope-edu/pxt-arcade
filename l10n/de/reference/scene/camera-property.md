# Kameraeigenschaft

Gibt eine Eigenschaft der Kamera zurück.

```sig
scene.cameraProperty(CameraProperty.Left)
```

## Beispiel

```blocks
let top = scene.cameraProperty(CameraProperty.Top)
```

## Eigenschaften

### x

Gibt die Bildschirmkoordinate der Kameramitte auf der x-Achse zurück.

### y

Gibt die Bildschirmkoordinate der Kameramitte auf der y-Achse zurück.

### left

Gibt die Bildschirmkoordinate des linken Kamerarands auf der x-Achse zurück.

### right

Gibt die Bildschirmkoordinate des rechten Kamerarands auf der x-Achse zurück.

### top

Gibt die Bildschirmkoordinate des oberen Kamerarands auf der y-Achse zurück.

### bottom

Gibt die Bildschirmkoordinate des unteren Kamerarands auf der y-Achse zurück.
