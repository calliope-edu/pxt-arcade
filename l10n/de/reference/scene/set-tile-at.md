# Kachel setzen an

Setze eine Kachel an eine Position in der Kachelkarte.

```sig
tiles.setTileAt(tiles.getTileLocation(0, 0), null)
```

Mit einem Kachelpositions-Objekt kannst du eine Kachel in eine bestimmte Spalte und Zeile der Kachelkarte setzen. Gib eine Kachel an, die in die Kachelkarte gesetzt werden soll, und eine Position dafür.

## Parameter

* **loc**: eine Kachelposition in der Kachelkarte.
* **tile**: die Kachel, die in die Kachelkarte gesetzt werden soll.

## Beispiel #example

Erstelle eine leere Kachelkarte und eine einfarbige Kachel. Setze die einfarbige Kachel an verschiedene Stellen der Kachelkarte und ersetze ihre vorherige Position durch eine transparente Kachel.

```blocks
tiles.setTilemap(tilemap`level1`)
let spot = tiles.getTileLocation(0, 0)
forever(function () {
    tiles.setTileAt(spot, assets.tile`transparency16`)
    spot = tiles.getTileLocation(randint(0, 9), randint(0, 6))
    tiles.setTileAt(spot, assets.tile`myTile`)
    pause(1000)
})
```
