# sage

Zeige neben einem Sprite eine Sprechblase mit Text an.

```sig
sprites.create(null).say("")
```

Manchmal möchtest du, dass bei einem Sprite eine Nachricht erscheint. Du kannst neben dem Sprite eine Sprechblase mit Text anzeigen lassen, damit es dem Spieler etwas sagt.

## Parameter

* **text**: eine [Zeichenkette](/types/string) mit dem Text der Sprechblase.
* **millis**: eine optionale [Zahl](/types/number) von Millisekunden, wie lange die Sprechblase angezeigt wird.
