# wenn Nachricht empfangen

Führe einen Teil eines Programms aus, wenn der @boardname@ eine
Nachricht über ``radio`` empfängt.

```sig
radio.onReceivedMessage(0, function() {})
```

## Parameter

* **msg**: Die Nachricht, auf die gewartet wird. Siehe [sende Nachricht](/reference/radio/send-message)
