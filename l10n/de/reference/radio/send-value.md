# sende Wert

Sende eine [Zeichenkette]() und eine [Zahl]() zusammen per ``radio`` an andere @boardname@s.
Die maximale Länge der [Zeichenkette]() beträgt 8 Zeichen.

```sig
radio.sendValue("name", 0);
```

## Parameter

* **name**: eine [Zeichenkette](/types/string), die der Name des zu sendenden Werts ist.
* **value**: eine [Zahl](/types/number), die der zu sendende Wert ist.
