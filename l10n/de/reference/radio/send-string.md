# sende Zeichenkette

Sendet eine Zeichenkette per Funk an andere @boardname@s in der Umgebung. Die
maximale Länge der Zeichenkette beträgt 19 Zeichen.

```sig
radio.sendString("Hello!")
```

## Parameter

* **msg**: eine [Zeichenkette](/types/string), die per Funk gesendet wird.
