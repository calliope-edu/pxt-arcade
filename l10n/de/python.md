# Python

Die Microsoft MakeCode Programmierumgebung verwendet JavaScript, sowie die Sprache [Static TypeScript](/javascript).

Diese Themen geben eine kurze Einführung in Python mit MakeCode:

* **[Aufrufen](/python/call)** - Wie man eine Funktion verwendet
* **[Sequenzierung](/python/sequence)** - Anweisungen im Code ordnen
* **[Variablen](/python/variables)** - sich an Daten erinnern und Werte speichern
* **[Operatoren](/python/operators)** - Vorgänge zum Ändern und Vergleichen von Werten
* **[Anweisungen](/python/statements)** - Die Elemente des Codes, die eine Aktion ausführen
* **[Funktionen](/python/functions)** - Codeteile die immer und immer wieder verwendet werden sollen
* **[Klassen](/python/classes)** - Enthält zusammengehörige Daten und Operationen
