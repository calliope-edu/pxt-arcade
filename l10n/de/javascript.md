# JavaScript

Die Microsoft MakeCode-Programmierumgebung verwendet JavaScript zusammen mit [statischem TypeScript](https://makecode.com/language).

Diese Themen geben eine kurze Einführung in JavaScript mit MakeCode:

* **[Aufruf](/javascript/call)** - Wie man eine Funktion verwendet
* **[Sequenzierung](/javascript/sequence)** - Reihenfolge der Anweisungen im Code
* **[Variablen](/javascript/variables)** - Daten merken und Werte speichern
* **[Operatoren](/javascript/operators)** - Operationen zum Ändern und Vergleichen von Werten
* **[Statements](/javascript/statements)** - Die Elemente des Codes, die eine Aktion ausführen
* **[Funktionen](/javascript/functions)** - Teile des Codes zur wiederholten Verwendung
* **[Types](/javascript/types)** - Die Identität der Daten
* **[Klassen](/javascript/classes)** - Enthalten zusammengehörige Daten und Operationen
* **[Schnittstellen](/javascript/interfaces)** - Ein regulärer Weg, um mit einer Klasse zu arbeiten
* **[Generik](/javascript/generics)** - Verschiedene Daten mit demselben Code verwenden
